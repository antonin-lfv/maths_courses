Tribus, tribu borélienne, mesures positives, mesure de Lebesgue et ensembles négligeables.

{{< sommaire >}}

{{% fiche %}}
**Tribu** - contient \(X\), stable par complémentaire et par réunion dénombrable (donc par intersection dénombrable). **Tribu engendrée** \(\sigma(\mathcal{C})\) : la plus petite contenant \(\mathcal{C}\).

**Boréliens** - \(\mathcal{B}(\mathbb{R})\) : tribu engendrée par les ouverts, ou par les intervalles \({]-\infty, a]}\), ou \({]a, b[}\).

**Mesure** - \({\mu(\varnothing) = 0}\) et \(\sigma\)-additivité. **Finie** - \({\mu(X) < +\infty}\) ; **probabilité** - \({\mu(X) = 1}\) ; **\(\sigma\)-finie** - \(X\) réunion dénombrable de parties de mesure finie.

**Propriétés** - croissance ; \({\mu\left(\bigcup A_n\right) \leq \sum \mu(A_n)}\) ; continuité croissante : \({\mu\left(\bigcup \uparrow A_n\right) = \lim \mu(A_n)}\) ; continuité décroissante si \({\mu(A_0) < +\infty}\).

**Lebesgue** - unique mesure \(\lambda\) sur \(\mathcal{B}(\mathbb{R})\) telle que \({\lambda([a, b]) = b - a}\) ; invariante par translation ; \({\lambda(\{x\}) = 0}\) ; tout ensemble dénombrable est de mesure nulle.

**Presque partout** - vrai hors d’un ensemble négligeable. Une réunion dénombrable de négligeables est négligeable.

**Unicité** - deux mesures finies égales sur une classe stable par intersection finie qui engendre la tribu sont égales.
