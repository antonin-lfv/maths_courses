Inégalités de Hölder et de Minkowski, complétude des espaces \(L^p\), densité.

{{< sommaire >}}

{{% fiche %}}
**Norme** - \({\|f\|_p = \left(\displaystyle\int |f|^p\,\mathrm{d}\mu\right)^{1/p}}\) ; \({\|f\|_\infty}\) : borne supérieure essentielle. \(L^p\) : classes de fonctions égales presque partout.

**Exposants conjugués** - \({\dfrac{1}{p} + \dfrac{1}{q} = 1}\).

**Hölder** - \({\displaystyle\int |fg| \leq \|f\|_p\|g\|_q}\) ; \({p = q = 2}\) : Cauchy-Schwarz.

**Minkowski** - \({\|f + g\|_p \leq \|f\|_p + \|g\|_p}\).

**Riesz-Fischer** - \(L^p\) est un espace de Banach (\({1 \leq p \leq +\infty}\)) ; \(L^2\) est un espace de Hilbert. Toute suite convergente dans \(L^p\) a une suite extraite qui converge presque partout.

**Inclusions** - mesure finie : \({q \geq p \Rightarrow L^q \subset L^p}\), \({\|f\|_p \leq \mu(X)^{\frac{1}{p} - \frac{1}{q}}\|f\|_q}\). Suites : \({p \leq q \Rightarrow \ell^p \subset \ell^q}\). Sur \(\mathbb{R}\) : aucune inclusion.

**Densité** - pour \({p < +\infty}\) : fonctions étagées intégrables ; dans \(L^p(\mathbb{R}^d)\) : fonctions continues à support compact, \(\mathcal{C}^\infty\) à support compact.

**Jensen** - \(\varphi\) convexe, \(\mu\) probabilité : \({\varphi\left(\displaystyle\int f\,\mathrm{d}\mu\right) \leq \int \varphi(f)\,\mathrm{d}\mu}\).
