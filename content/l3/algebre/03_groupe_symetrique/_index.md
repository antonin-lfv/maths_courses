Cycles, classes de conjugaison, signature, groupe alterné et simplicité de \(\mathfrak{A}_n\).

{{< sommaire >}}

{{% fiche %}}
**Décomposition** - toute permutation est produit de cycles à supports disjoints, unique à l’ordre près ; ordre = PPCM des longueurs.

**Conjugaison** - \({\sigma(a_1\ \dots\ a_p)\sigma^{-1} = (\sigma(a_1)\ \dots\ \sigma(a_p))}\). Deux permutations sont conjuguées \(\iff\) elles ont le même **type** (mêmes longueurs de cycles).

**Classes de conjugaison de \(\mathfrak{S}_n\)** - autant que de partitions de l’entier \(n\).

**Générateurs** - les transpositions ; les \({(1\ i)}\) ; les \({(i\ \ i{+}1)}\) ; \({(1\ 2)}\) et \({(1\ 2\ \dots\ n)}\).

**Signature** - morphisme \({\mathfrak{S}_n \to \{\pm 1\}}\) ; \({\varepsilon(\sigma) = (-1)^{n - r}}\) où \(r\) est le nombre d’orbites (points fixes compris) ; \(p\)-cycle : \({(-1)^{p-1}}\).

**Groupe alterné** - \({\mathfrak{A}_n = \ker\varepsilon}\), d’ordre \(\dfrac{n!}{2}\), engendré par les \(3\)-cycles.

**Simplicité** - \(\mathfrak{A}_n\) est simple pour \({n \geq 5}\) ; \(\mathfrak{A}_4\) ne l’est pas (groupe de Klein distingué).

**Centre** - \({Z(\mathfrak{S}_n) = \{\mathrm{id}\}}\) pour \({n \geq 3}\).
