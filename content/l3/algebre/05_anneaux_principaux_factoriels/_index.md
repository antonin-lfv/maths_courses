Divisibilité dans un anneau intègre, éléments irréductibles et premiers, critères d’irréductibilité des polynômes.

{{< sommaire >}}

{{% fiche %}}
**Hiérarchie** - euclidien \(\Rightarrow\) principal \(\Rightarrow\) factoriel \(\Rightarrow\) intègre. Aucune réciproque.

**Irréductible** - non nul, non inversible, \({p = ab \Rightarrow a \text{ ou } b}\) inversible. **Premier** - \({p \mid ab \Rightarrow p \mid a \text{ ou } p \mid b}\). Premier \(\Rightarrow\) irréductible ; équivalents dans un anneau factoriel.

**Euclidien** - division avec reste « plus petit » (stathme). Exemples : \(\mathbb{Z}\) (\(|n|\)), \(\mathbb{K}[X]\) (degré), \(\mathbb{Z}[i]\) (\({a^2 + b^2}\)).

**Principal** - tout idéal est engendré par un élément : PGCD, Bézout, Gauss ; \((p)\) maximal \(\iff\) \(p\) irréductible.

**Factoriel** - décomposition unique en irréductibles. \(A\) factoriel \(\Rightarrow\) \(A[X]\) factoriel (\(\mathbb{Z}[X]\), \(\mathbb{K}[X, Y]\), non principaux).

**Irréductibilité dans \(\mathbb{Q}[X]\)** - degré 2 ou 3 : pas de racine ; racines rationnelles \(\dfrac{p}{q}\) : \({p \mid a_0}\), \({q \mid a_n}\) ; Eisenstein ; réduction modulo \(p\).

**Lemme de Gauss** - le contenu d’un produit est le produit des contenus ; irréductible dans \(\mathbb{Z}[X]\) (primitif) \(\iff\) irréductible dans \(\mathbb{Q}[X]\).
