Extensions, degré, éléments algébriques, polynôme minimal, corps de rupture et corps finis.

{{< sommaire >}}

{{% fiche %}}
**Degré** - \({[L : K] = \dim_K L}\). **Multiplicativité** - \({[M : K] = [M : L][L : K]}\).

**Algébrique** - \(\alpha\) racine d’un polynôme non nul de \(K[X]\) ; sinon transcendant.

**Polynôme minimal** - \(\mu_\alpha\) : unitaire, irréductible, engendre l’idéal des polynômes annulateurs. \({K(\alpha) = K[\alpha] \simeq K[X]/(\mu_\alpha)}\), de base \({(1, \alpha, \dots, \alpha^{n-1})}\), \({[K(\alpha) : K] = \deg\mu_\alpha}\).

**Finie \(\Rightarrow\) algébrique** - les algébriques sur \(K\) forment un corps.

**Corps de rupture** - \(K[X]/(P)\) pour \(P\) irréductible : \(P\) y a une racine. **Corps de décomposition** - plus petite extension où \(P\) est scindé.

**Corps finis** - cardinal \({q = p^n}\) ; unique à isomorphisme près, noté \(\mathbb{F}_q\) ; \(\mathbb{F}_q^\times\) est cyclique ; \({x^q = x}\) pour tout \(x\) ; \({\mathbb{F}_{p^m} \subset \mathbb{F}_{p^n} \iff m \mid n}\).

**Règle et compas** - un nombre constructible est algébrique de degré \(2^k\) sur \(\mathbb{Q}\).
