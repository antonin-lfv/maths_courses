Le vocabulaire de la logique et les grands types de raisonnement, qui servent dans tous les autres chapitres.

{{< sommaire >}}

{{% fiche %}}
**Connecteurs** - \({\text{non } P}\), \({P \text{ et } Q}\), \({P \text{ ou } Q}\) (ou inclusif), \({P \Rightarrow Q}\) (fausse seulement si \(P\) est vraie et \(Q\) fausse), \({P \iff Q}\).

**Négations** - \({\text{non}(P \text{ et } Q)}\) équivaut à \({(\text{non } P) \text{ ou } (\text{non } Q)}\) ; \({\text{non}(P \text{ ou } Q)}\) équivaut à \({(\text{non } P) \text{ et } (\text{non } Q)}\) ; \({\text{non}(P \Rightarrow Q)}\) équivaut à \({P \text{ et } (\text{non } Q)}\).

**Quantificateurs** - la négation de \({\forall x \in E,\ P(x)}\) est \({\exists x \in E,\ \text{non } P(x)}\), et inversement. On ne peut pas échanger un \(\forall\) et un \(\exists\).

**Contraposée** - \({P \Rightarrow Q}\) équivaut à \({(\text{non } Q) \Rightarrow (\text{non } P)}\). La réciproque \({Q \Rightarrow P}\) est une autre assertion.

**Raisonnements** - direct, par contraposée, par l’absurde, par disjonction de cas, par récurrence (simple, double, forte), par analyse-synthèse, par contre-exemple pour réfuter un « pour tout ».
