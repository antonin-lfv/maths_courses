Forme algébrique, module et argument, exponentielle complexe, racines \(n\)-ièmes et équations du second degré à coefficients complexes.

{{< sommaire >}}

{{% fiche %}}
**Module** - \({|z|^2 = z\overline{z}}\) ; \({|zz'| = |z||z'|}\) ; inégalité triangulaire \({\big||z| - |z'|\big| \leq |z + z'| \leq |z| + |z'|}\).

**Forme exponentielle** - \({z = re^{i\theta}}\) avec \({r = |z| > 0}\), \({\theta = \arg z \ [2\pi]}\) ; \({e^{i\theta}e^{i\theta'} = e^{i(\theta + \theta')}}\).

**Euler** - \({\cos\theta = \dfrac{e^{i\theta} + e^{-i\theta}}{2}}\), \({\sin\theta = \dfrac{e^{i\theta} - e^{-i\theta}}{2i}}\). **Moivre** - \({(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta)}\).

**Angle moitié** - \({1 + e^{i\theta} = 2\cos\dfrac{\theta}{2}\,e^{i\theta/2}}\) ; \({e^{ip} + e^{iq} = 2\cos\dfrac{p-q}{2}\,e^{i(p+q)/2}}\).

**Racines \(n\)-ièmes de l’unité** - \({\omega_k = e^{2ik\pi/n}}\), \({0 \leq k \leq n-1}\) ; leur somme est nulle si \({n \geq 2}\).

**Racines \(n\)-ièmes de \({a = re^{i\theta}}\)** - \({z_k = r^{1/n}e^{i(\theta + 2k\pi)/n}}\), \({0 \leq k \leq n-1}\).

**Second degré** - \({az^2 + bz + c = 0}\), \({\Delta = b^2 - 4ac}\), \(\delta\) une racine carrée de \(\Delta\) : \({z = \dfrac{-b \pm \delta}{2a}}\) ; somme \({-\dfrac{b}{a}}\), produit \(\dfrac{c}{a}\).

**Exponentielle complexe** - \({e^{x+iy} = e^x e^{iy}}\) ; \({e^z = e^{z'} \iff z - z' \in 2i\pi\mathbb{Z}}\).
