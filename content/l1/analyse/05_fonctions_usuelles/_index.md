Logarithme, exponentielle, puissances, fonctions hyperboliques et fonctions trigonométriques réciproques.

{{< sommaire >}}

{{% fiche %}}
**Puissances** - \({x^\alpha = e^{\alpha\ln x}}\) pour \({x > 0}\) ; \({(x^\alpha)' = \alpha x^{\alpha - 1}}\) ; \({(u^v)' }\) : passer par \({e^{v\ln u}}\).

**Hyperboliques** - \({\operatorname{ch} x = \dfrac{e^x + e^{-x}}{2}}\), \({\operatorname{sh} x = \dfrac{e^x - e^{-x}}{2}}\) ; \({\operatorname{ch}^2 x - \operatorname{sh}^2 x = 1}\) ; \({\operatorname{ch}' = \operatorname{sh}}\), \({\operatorname{sh}' = \operatorname{ch}}\), \({\operatorname{th}' = 1 - \operatorname{th}^2}\).

**Arcsin** - \({[-1, 1] \to \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]}\), dérivée \(\dfrac{1}{\sqrt{1 - x^2}}\) sur \({]-1, 1[}\).

**Arccos** - \({[-1, 1] \to [0, \pi]}\), dérivée \(-\dfrac{1}{\sqrt{1 - x^2}}\) ; \({\arcsin x + \arccos x = \dfrac{\pi}{2}}\).

**Arctan** - \({\mathbb{R} \to \left]-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right[}\), dérivée \(\dfrac{1}{1 + x^2}\) ; \({\arctan x + \arctan\dfrac{1}{x} = \pm\dfrac{\pi}{2}}\) selon le signe de \(x\).

**Piège** - \({\arcsin(\sin x) = x}\) seulement si \({x \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]}\).
