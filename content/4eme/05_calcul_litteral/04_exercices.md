### Exercice 1

Réduire : a) \({6x - (2x + 3)}\) ; b) \({4 - (7 - y) + 2y}\) ; c) \({-(a - 5) + (3a - 1)}\).

{{% details title="Solution" closed="true" %}}
a) \({4x - 3}\) ; b) \({3y - 3}\) ; c) \({2a + 4}\).
{{% /details %}}

### Exercice 2

Développer et réduire : a) \({4(3x - 2)}\) ; b) \({-3(x + 6)}\) ; c) \({2(x - 1) - 5(x + 2)}\).

{{% details title="Solution" closed="true" %}}
a) \({12x - 8}\) ; b) \({-3x - 18}\) ; c) \({2x - 2 - 5x - 10 = -3x - 12}\).
{{% /details %}}

### Exercice 3

Factoriser : a) \({8x + 12}\) ; b) \({x^2 - 9x}\) ; c) \({15a - 10ab}\).

{{% details title="Solution" closed="true" %}}
a) \({4(2x + 3)}\) ; b) \({x(x - 9)}\) ; c) \({5a(3 - 2b)}\).
{{% /details %}}

### Exercice 4

L’égalité \({2(x + 3) - x = x + 6}\) est-elle vraie pour tout nombre \(x\) ? Et l’égalité \({x^2 + x = 2x}\) ?

{{% details title="Solution" closed="true" %}}
\({2(x + 3) - x = 2x + 6 - x = x + 6}\) : vraie pour tout \(x\). Pour la seconde, avec \({x = 2}\) : \({4 + 2 = 6}\) et \({2 \times 2 = 4}\) : elle n’est pas vraie pour tout \(x\).
{{% /details %}}
