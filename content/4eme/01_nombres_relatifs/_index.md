Cours du chapitre 1 : Nombres relatifs.

{{< sommaire >}}

{{% fiche %}}
**Addition** - même signe : on garde le signe, on ajoute les distances à zéro ; signes contraires : signe du plus éloigné de zéro, on soustrait les distances.

**Soustraction** - on ajoute l’opposé ; sommes algébriques : transformer en additions, regrouper positifs et négatifs.

**Multiplication** - même signe : positif ; signes contraires : négatif. \({a \times 0 = 0}\), \({a \times (-1) = -a}\). Nombre pair de facteurs négatifs : produit positif ; impair : négatif.

**Division** - mêmes règles de signes ; \({\dfrac{-a}{-b} = \dfrac{a}{b}}\) et \({\dfrac{-a}{b} = \dfrac{a}{-b} = -\dfrac{a}{b}}\) ; jamais de division par \(0\).
