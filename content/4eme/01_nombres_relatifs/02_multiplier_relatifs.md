## Produit de deux nombres relatifs

> [!TIP] **Définition**
>
> Pour calculer le produit de deux nombres relatifs, on détermine son signe, puis on multiplie les distances à zéro :
> - le produit de deux nombres relatifs de **même signe** est **positif** ;
> - le produit de deux nombres relatifs de **signes contraires** est **négatif**.

{{% details title="Exemple" closed="true" %}}
\({4 \times 7 = 28}\) ; \({(-4) \times (-7) = 28}\) ; \({4 \times (-7) = -28}\) ; \({(-0{,}5) \times 6 = -3}\).
{{% /details %}}

## Produit de plusieurs nombres relatifs

> [!TIP] **Propriété**
>
> Pour calculer le produit de plusieurs nombres relatifs, on peut changer l’ordre des facteurs et effectuer les multiplications dans n’importe quel ordre.

{{% details title="Exemple" closed="true" %}}
\((-25) \times 7 \times (-4) = (-25) \times (-4) \times 7 = 100 \times 7 = 700\).
{{% /details %}}

> [!TIP] **Propriétés**
>
> \(a\) désigne un nombre relatif.
> - Le produit d’un nombre relatif par \(0\) est égal à \(0\) : \({a \times 0 = 0}\).
> - Le produit d’un nombre relatif par \({-1}\) est égal à son opposé : \({a \times (-1) = -a}\).

> [!IMPORTANT] **Remarque**
>
> Attention : le nombre \({-a}\) n’est pas forcément négatif. Si \({a = -3}\), alors \({-a = 3}\).

> [!TIP] **Propriété**
>
> Pour déterminer le signe d’un produit de plusieurs facteurs non nuls, on compte le nombre de facteurs négatifs :
> - s’il y en a un nombre **pair**, alors le produit est **positif** ;
> - s’il y en a un nombre **impair**, alors le produit est **négatif**.

{{% details title="Exemple" closed="true" %}}
- \({D = (-2) \times 5 \times (-1) \times (-3)}\) : trois facteurs négatifs (nombre impair), donc \(D\) est négatif : \({D = -30}\).
- \(E = (-1)^4 \times 6 = (-1) \times (-1) \times (-1) \times (-1) \times 6\) : quatre facteurs négatifs, \({E = 6}\).
{{% /details %}}

## S’entraîner

> [!NOTE] **Exercice résolu**
>
> Sans calculer, donner le signe de \(F = (-3{,}1) \times (-2) \times 7 \times (-0{,}4) \times (-5)\), puis calculer \(F\).

{{% details title="Solution commentée" closed="true" %}}
Il y a quatre facteurs négatifs (nombre pair) : \(F\) est positif. On calcule les distances à zéro en regroupant astucieusement : \({2 \times 5 = 10}\) et \({3{,}1 \times 7 \times 0{,}4 = 3{,}1 \times 2{,}8 = 8{,}68}\), donc \({F = 10 \times 8{,}68 = 86{,}8}\).
{{% /details %}}
