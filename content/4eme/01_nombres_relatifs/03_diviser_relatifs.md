## Quotient de deux nombres relatifs

> [!TIP] **Définition**
>
> \(a\) et \(b\) désignent des nombres relatifs (\(b \neq 0\)). Le **quotient** de \(a\) par \(b\) est le nombre qui, multiplié par \(b\), donne \(a\) :
> \[
\frac{a}{b} \times b = a.
\]

{{% details title="Exemple" closed="true" %}}
\(\dfrac{-12}{4} = -3\) car \((-3) \times 4 = -12\). On ne peut jamais diviser par \(0\).
{{% /details %}}

> [!TIP] **Propriété**
>
> Pour calculer un quotient, on détermine son signe, puis on divise les distances à zéro :
> - le quotient de deux nombres relatifs de **même signe** est **positif** ;
> - le quotient de deux nombres relatifs de **signes contraires** est **négatif**.

{{% details title="Exemple" closed="true" %}}
- \(\dfrac{-24}{-6}\) : même signe, positif ; \(24 \div 6 = 4\). Donc \(\dfrac{-24}{-6} = 4\).
- \(\dfrac{15}{-4}\) : signes contraires, négatif ; \(15 \div 4 = 3{,}75\). Donc \(\dfrac{15}{-4} = -3{,}75\).
{{% /details %}}

> [!TIP] **Propriété**
>
> \(a\) et \(b\) désignent des nombres relatifs (\(b \neq 0\)) :
> \[
\frac{-a}{-b} = \frac{a}{b} \qquad \text{et} \qquad \frac{-a}{b} = \frac{a}{-b} = -\frac{a}{b}.
\]

{{% details title="Exemple" closed="true" %}}
\(\dfrac{-5}{8} = \dfrac{5}{-8} = -\dfrac{5}{8}\) : ces trois quotients sont négatifs et égaux. \(\dfrac{-7}{-3} = \dfrac{7}{3}\).
{{% /details %}}

## S’entraîner

> [!NOTE] **Exercice résolu**
>
> Calculer : \(G = \dfrac{-36}{9}\) ; \(H = \dfrac{(-6) \times (-5)}{-10}\) ; \(K = \dfrac{-2 - 10}{3 - 7}\).

{{% details title="Solution commentée" closed="true" %}}
- \(G = -4\).
- Le numérateur vaut \(30\) ; \(H = \dfrac{30}{-10} = -3\).
- Numérateur : \(-12\) ; dénominateur : \(-4\). \(K = \dfrac{-12}{-4} = 3\).
{{% /details %}}
