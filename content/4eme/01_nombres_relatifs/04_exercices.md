### Exercice 1

Calculer : a) \({(-8) + (-5{,}5)}\) ; b) \({3 - 11}\) ; c) \({-4 - (-9)}\) ; d) \({A = 6 - 13 + (-2) - (-7)}\).

{{% details title="Solution" closed="true" %}}
a) \({-13{,}5}\) ; b) \({-8}\) ; c) \(5\) ; d) \(A = (6 + 7) + \big((-13) + (-2)\big) = 13 + (-15) = -2\).
{{% /details %}}

### Exercice 2

Calculer : a) \({(-6) \times (-9)}\) ; b) \({7 \times (-0{,}3)}\) ; c) \({(-2)^3}\) ; d) \({(-1) \times (-4) \times (-5) \times 2}\).

{{% details title="Solution" closed="true" %}}
a) \(54\) ; b) \({-2{,}1}\) ; c) \({-8}\) ; d) trois facteurs négatifs : \({-40}\).
{{% /details %}}

### Exercice 3

Calculer : a) \({\dfrac{-45}{-5}}\) ; b) \({\dfrac{18}{-12}}\) ; c) \({\dfrac{4 - 10}{-3}}\).

{{% details title="Solution" closed="true" %}}
a) \(9\) ; b) \({-1{,}5}\) ; c) \({\dfrac{-6}{-3} = 2}\).
{{% /details %}}

### Exercice 4

Calculer en respectant les priorités : \({B = -3 + 4 \times (-5)}\) ; \({C = (-3 + 4) \times (-5)}\) ; \({D = 2 \times (-3)^2 - 7}\).

{{% details title="Solution" closed="true" %}}
\({B = -3 + (-20) = -23}\) ; \({C = 1 \times (-5) = -5}\) ; \({D = 2 \times 9 - 7 = 11}\).
{{% /details %}}
