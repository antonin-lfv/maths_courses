## Même dénominateur

> [!TIP] **Propriété**
>
> Pour additionner (ou soustraire) deux fractions qui ont le même dénominateur, on additionne (ou on soustrait) les numérateurs et on garde le dénominateur commun. \(a\), \(b\) et \(c\) désignent trois nombres relatifs (\({c \neq 0}\)) :
> \[
\dfrac{a}{c} + \dfrac{b}{c} = \dfrac{a + b}{c} \qquad \text{et} \qquad \dfrac{a}{c} - \dfrac{b}{c} = \dfrac{a - b}{c}.
\]

{{% details title="Démonstration" closed="true" %}}
D’après la définition du quotient, \({\dfrac{a}{c} \times c = a}\) et \({\dfrac{b}{c} \times c = b}\). Donc \({\left(\dfrac{a}{c} + \dfrac{b}{c}\right) \times c = \dfrac{a}{c} \times c + \dfrac{b}{c} \times c = a + b}\). Le nombre \({\dfrac{a}{c} + \dfrac{b}{c}}\), multiplié par \(c\), donne \({a + b}\) : c’est donc \({\dfrac{a + b}{c}}\).
{{% /details %}}

{{% details title="Exemple" closed="true" %}}
\({\dfrac{-4}{9} + \dfrac{7}{9} = \dfrac{3}{9} = \dfrac{1}{3}}\) ; \({\dfrac{2}{5} - \dfrac{8}{5} = \dfrac{-6}{5}}\).
{{% /details %}}

## Dénominateurs différents

> [!NOTE] **Méthode - Additionner ou soustraire deux fractions de dénominateurs différents**
>
> On écrit d’abord les deux fractions avec le même dénominateur, puis on applique la propriété précédente. Pour éviter des calculs compliqués, on cherche de préférence le plus petit multiple commun aux deux dénominateurs.

{{% details title="Exemple" closed="true" %}}
- \({\dfrac{3}{4} + \dfrac{-1}{6}}\) : \(12\) est le plus petit multiple commun de \(4\) et \(6\). \({\dfrac{9}{12} + \dfrac{-2}{12} = \dfrac{7}{12}}\).
- \({\dfrac{2}{3} - \dfrac{5}{7} = \dfrac{14}{21} - \dfrac{15}{21} = \dfrac{-1}{21}}\) (ici le multiple commun est le produit \({3 \times 7}\)).
{{% /details %}}

> [!IMPORTANT] **Remarque**
>
> Le produit des deux dénominateurs est toujours un multiple commun, mais ce n’est pas forcément le plus petit : pour \({\dfrac{1}{8} + \dfrac{1}{12}}\), on peut prendre \(24\) plutôt que \(96\) : \({\dfrac{3}{24} + \dfrac{2}{24} = \dfrac{5}{24}}\).

## S’entraîner

> [!NOTE] **Exercice résolu**
>
> Calculer et simplifier : \({A = \dfrac{5}{6} - \dfrac{7}{9}}\) ; \({B = 2 - \dfrac{3}{8} + \dfrac{-1}{4}}\).

{{% details title="Solution commentée" closed="true" %}}
- \(18\) est le plus petit multiple commun de \(6\) et \(9\) : \({A = \dfrac{15}{18} - \dfrac{14}{18} = \dfrac{1}{18}}\).
- Avec le dénominateur \(8\) : \({B = \dfrac{16}{8} - \dfrac{3}{8} + \dfrac{-2}{8} = \dfrac{11}{8}}\).
{{% /details %}}
