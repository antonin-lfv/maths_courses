## Quotient et fraction

> [!TIP] **Définitions**
>
> \(a\) et \(b\) désignent deux nombres relatifs (\({b \neq 0}\)).
> - Le **quotient** de \(a\) par \(b\) est le nombre qui, multiplié par \(b\), donne \(a\). On le note \(\dfrac{a}{b}\) ou \({a \div b}\).
> - Si \(a\) et \(b\) sont des entiers, on dit que \(\dfrac{a}{b}\) est une **fraction** ; \(a\) est le numérateur et \(b\) le dénominateur.

{{% details title="Exemple" closed="true" %}}
Le quotient de \(7\) par \(4\) est \(\dfrac{7}{4}\), le nombre qui, multiplié par \(4\), donne \(7\) : \({\dfrac{7}{4} \times 4 = 7}\). Comme \(7\) et \(4\) sont entiers, c’est une fraction.
{{% /details %}}

> [!IMPORTANT] **Remarque**
>
> On ne peut jamais diviser par \(0\).

## Nombres rationnels et nombres décimaux

> [!TIP] **Définition**
>
> Un nombre qui peut s’écrire sous la forme d’une fraction est appelé **nombre rationnel**.

{{% details title="Exemple" closed="true" %}}
\({\dfrac{-5}{9}}\) est un nombre rationnel. \(3{,}6\) est aussi un nombre rationnel, car \({3{,}6 = \dfrac{18}{5}}\). Tout nombre entier est rationnel : \({-4 = \dfrac{-4}{1}}\).
{{% /details %}}

> [!TIP] **Définitions**
>
> - Si \(a\) est un entier et \(b\) est égal à \(10\), \(100\), \(1\,000\)…, on dit que \(\dfrac{a}{b}\) est une **fraction décimale**.
> - Un **nombre décimal** est un nombre qui peut s’écrire sous la forme d’une fraction décimale.

{{% details title="Exemple" closed="true" %}}
\(\dfrac{247}{100}\) est une fraction décimale. \({2{,}47 = \dfrac{247}{100}}\) est un nombre décimal. \({\dfrac{3}{4} = \dfrac{75}{100} = 0{,}75}\) est aussi un nombre décimal.
{{% /details %}}

> [!IMPORTANT] **Remarque**
>
> Tout nombre décimal (et donc tout nombre entier) est un nombre rationnel. En revanche, un nombre rationnel n’est pas toujours un nombre décimal : la division de \(5\) par \(6\) ne se termine jamais (\(0{,}8333\dots\)), donc \(\dfrac{5}{6}\) n’est pas décimal. On peut seulement en donner une valeur approchée : \({\dfrac{5}{6} \approx 0{,}833}\).

## S’entraîner

> [!NOTE] **Exercice résolu**
>
> Parmi les nombres \(\dfrac{9}{20}\), \(\dfrac{4}{3}\), \({-6}\), \(\dfrac{7}{8}\), lesquels sont décimaux ? Lesquels sont rationnels ?

{{% details title="Solution commentée" closed="true" %}}
Tous sont rationnels (ce sont des fractions ou des entiers). \({\dfrac{9}{20} = \dfrac{45}{100} = 0{,}45}\) est décimal ; \({-6}\) est décimal ; \({\dfrac{7}{8} = 0{,}875}\) est décimal ; \({\dfrac{4}{3} = 1{,}333\dots}\) n’est pas décimal.
{{% /details %}}
