Cours du chapitre 2 : Nombres rationnels (addition, soustraction, comparaison).

{{< sommaire >}}

{{% fiche %}}
**Divisibilité** - \({a = b \times q + r}\), \({r < b}\) ; multiples, diviseurs ; critères par \(2\), \(3\), \(5\), \(9\), \(10\). Nombre premier : exactement deux diviseurs (\(0\) et \(1\) ne le sont pas, \(2\) est le seul pair) ; décomposition en facteurs premiers.

**Rationnels** - quotient de deux entiers ; décimal : fraction décimale ; tout décimal est rationnel, pas l’inverse (\(\dfrac{5}{6}\)).

**Comparer** - simplifier ; produits en croix : \({\dfrac{a}{b} = \dfrac{c}{d} \iff ad = bc}\) ; même dénominateur positif : comparer les numérateurs.

**Additionner, soustraire** - même dénominateur ; sinon, plus petit multiple commun des dénominateurs.
