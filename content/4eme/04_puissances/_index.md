Cours du chapitre 4 : Puissances.

{{< sommaire >}}

{{% fiche %}}
**Puissances de 10** - \({10^n = 1}\) suivi de \(n\) zéros ; \({10^0 = 1}\) ; \({10^{-n} = \dfrac{1}{10^n} = 0{,}0\dots01}\) ; \({10^m \times 10^n = 10^{m+n}}\). Préfixes : kilo \(10^3\), méga \(10^6\), giga \(10^9\), milli \({10^{-3}}\), micro \({10^{-6}}\), nano \({10^{-9}}\).

**Notation scientifique** - \({a \times 10^n}\) avec \({1 \leq a < 10}\) ; donne un ordre de grandeur.

**Puissances d’un relatif** - \(a^n\) : produit de \(n\) facteurs \(a\) ; \({a^1 = a}\), \({a^0 = 1}\). Priorité aux puissances ; \({(-3)^2 = 9}\) mais \({-3^2 = -9}\).
