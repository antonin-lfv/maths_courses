### Exercice 1

Écrire en écriture décimale : a) \(10^7\) ; b) \(10^{-3}\) ; c) \(4{,}5 \times 10^4\) ; d) \(8 \times 10^{-5}\).

{{% details title="Solution" closed="true" %}}
a) \(10\,000\,000\) ; b) \(0{,}001\) ; c) \(45\,000\) ; d) \(0{,}000\,08\).
{{% /details %}}

### Exercice 2

Donner la notation scientifique : a) \(93\,000\,000\) ; b) \(0{,}000\,605\) ; c) \(0{,}7 \times 10^5\).

{{% details title="Solution" closed="true" %}}
a) \(9{,}3 \times 10^7\) ; b) \(6{,}05 \times 10^{-4}\) ; c) \(7 \times 10^4\).
{{% /details %}}

### Exercice 3

Convertir : a) \(12\) km en m ; b) \(3\) Mo en octets ; c) \(250\) µm en m.

{{% details title="Solution" closed="true" %}}
a) \(12 \times 10^3 = 12\,000\) m ; b) \(3 \times 10^6 = 3\,000\,000\) octets ; c) \(250 \times 10^{-6} = 2{,}5 \times 10^{-4}\) m.
{{% /details %}}

### Exercice 4

Calculer : \(A = 5 - 2 \times 3^2\) ; \(B = (-4)^3\) ; \(C = 2 \times 10^3 + 3 \times 10^2 + 7\).

{{% details title="Solution" closed="true" %}}
\(A = 5 - 18 = -13\) ; \(B = -64\) ; \(C = 2\,000 + 300 + 7 = 2\,307\).
{{% /details %}}
