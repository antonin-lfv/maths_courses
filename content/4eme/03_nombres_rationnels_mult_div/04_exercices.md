### Exercice 1

Calculer et simplifier : a) \(\dfrac{3}{8} \times \dfrac{4}{9}\) ; b) \(-6 \times \dfrac{5}{12}\) ; c) \(\dfrac{-10}{21} \times \dfrac{-7}{15}\).

{{% details title="Solution" closed="true" %}}
a) \(\dfrac{12}{72} = \dfrac{1}{6}\) ; b) \(\dfrac{-30}{12} = -\dfrac{5}{2}\) ; c) \(\dfrac{70}{315} = \dfrac{2}{9}\).
{{% /details %}}

### Exercice 2

Donner l’inverse de : \(7\) ; \(-\dfrac{2}{9}\) ; \(0{,}1\) ; \(-1\).

{{% details title="Solution" closed="true" %}}
\(\dfrac{1}{7}\) ; \(-\dfrac{9}{2}\) ; \(10\) ; \(-1\).
{{% /details %}}

### Exercice 3

Calculer : a) \(\dfrac{4}{5} \div \dfrac{8}{15}\) ; b) \(\dfrac{-3}{2} \div 6\) ; c) \(5 \div \dfrac{-10}{3}\).

{{% details title="Solution" closed="true" %}}
a) \(\dfrac{4}{5} \times \dfrac{15}{8} = \dfrac{60}{40} = \dfrac{3}{2}\) ; b) \(\dfrac{-3}{12} = -\dfrac{1}{4}\) ; c) \(5 \times \dfrac{3}{-10} = -\dfrac{3}{2}\).
{{% /details %}}

### Exercice 4

Une famille consacre les \(\dfrac{2}{5}\) de son budget mensuel au logement, et le quart du reste à l’alimentation. Quelle fraction du budget est consacrée à l’alimentation ?

{{% details title="Solution" closed="true" %}}
Reste après le logement : \(1 - \dfrac{2}{5} = \dfrac{3}{5}\). Alimentation : \(\dfrac{1}{4} \times \dfrac{3}{5} = \dfrac{3}{20}\) du budget.
{{% /details %}}
