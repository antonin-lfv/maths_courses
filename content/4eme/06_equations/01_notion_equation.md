## Équation

> [!TIP] **Définition**
>
> Une **équation** est une égalité qui comporte au moins un nombre de valeur inconnue, généralement désigné par une lettre. Cette égalité peut être vraie pour certaines valeurs de l’inconnue et fausse pour d’autres.

{{% details title="Exemple" closed="true" %}}
\({2x + 5 = 13}\) est une équation d’inconnue \(x\).
- Si \({x = 4}\) : \({2 \times 4 + 5 = 13}\), l’égalité est vraie.
- Si \({x = 3}\) : \({2 \times 3 + 5 = 11 \neq 13}\), l’égalité est fausse.
{{% /details %}}

## Solution

> [!TIP] **Définition**
>
> Une **solution** d’une équation est une valeur de l’inconnue pour laquelle l’égalité est vraie.

> [!NOTE] **Méthode - Tester si un nombre est solution d’une équation**
>
> - On calcule le membre de gauche en remplaçant l’inconnue par la valeur donnée ;
> - on calcule le membre de droite en remplaçant l’inconnue par cette même valeur ;
> - on compare les résultats et on conclut.

{{% details title="Exemple" closed="true" %}}
Les nombres \(3\) et \({-1}\) sont-ils solutions de l’équation \({4x - 1 = x + 8}\) ?
- Pour \({x = 3}\) : membre de gauche \({4 \times 3 - 1 = 11}\) ; membre de droite \({3 + 8 = 11}\). Les deux membres sont égaux : \(3\) est une solution.
- Pour \({x = -1}\) : \({4 \times (-1) - 1 = -5}\) et \({-1 + 8 = 7}\). Les membres sont différents : \({-1}\) n’est pas solution.
{{% /details %}}

## S’entraîner

> [!NOTE] **Exercice résolu**
>
> Le nombre \({-2}\) est-il solution de \({x^2 + 3x = -2}\) ? Et le nombre \({-1}\) ?

{{% details title="Solution commentée" closed="true" %}}
- Pour \({x = -2}\) : \({(-2)^2 + 3 \times (-2) = 4 - 6 = -2}\). Oui, \({-2}\) est solution.
- Pour \({x = -1}\) : \({(-1)^2 + 3 \times (-1) = 1 - 3 = -2}\). Oui, \({-1}\) est aussi solution : une équation peut avoir plusieurs solutions.
{{% /details %}}
