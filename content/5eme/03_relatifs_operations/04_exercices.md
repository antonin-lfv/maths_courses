### Exercice 1

Calculer : a) \((-7) + (-13)\) ; b) \(-25 + 16\) ; c) \(4{,}8 + (-1{,}3)\) ; d) \((-0{,}6) + 0{,}6\).

{{% details title="Solution" closed="true" %}}
a) \(-20\) ; b) \(-9\) ; c) \(3{,}5\) ; d) \(0\).
{{% /details %}}

### Exercice 2

Calculer : a) \(5 - 12\) ; b) \(-3 - 8\) ; c) \(-6 - (-11)\) ; d) \(2{,}5 - (-2{,}5)\).

{{% details title="Solution" closed="true" %}}
a) \(-7\) ; b) \(-11\) ; c) \(5\) ; d) \(5\).
{{% /details %}}

### Exercice 3

Calculer \(F = 15 - 20 + 8 - (-3) - 11\).

{{% details title="Solution" closed="true" %}}
\(F = 15 + (-20) + 8 + 3 + (-11) = 26 + (-31) = -5\).
{{% /details %}}

### Exercice 4

Sur une droite graduée, \(M\) a pour abscisse \(-6{,}5\) et \(N\) a pour abscisse \(-1\). Calculer la distance \(MN\).

{{% details title="Solution" closed="true" %}}
\(MN = -1 - (-6{,}5) = -1 + 6{,}5 = 5{,}5\).
{{% /details %}}

### Exercice 5

Un compte bancaire affiche \(-35\) €. On y dépose \(120\) €, puis on paie un achat de \(64\) €. Quel est le nouveau solde ?

{{% details title="Solution" closed="true" %}}
\(-35 + 120 - 64 = 120 + \big((-35) + (-64)\big) = 120 + (-99) = 21\) €.
{{% /details %}}
