## Deux nombres de même signe

> [!TIP] **Définition**
>
> La somme de deux nombres relatifs de **même signe** est le nombre qui a :
> - le même signe que les deux nombres ;
> - pour valeur absolue la **somme** de leurs valeurs absolues.

{{% details title="Exemple" closed="true" %}}
- \({4{,}5 + 2{,}3}\) : deux nombres positifs, la somme est positive : \({4{,}5 + 2{,}3 = 6{,}8}\).
- \({(-6) + (-9)}\) : deux nombres négatifs, la somme est négative ; on ajoute les valeurs absolues : \({(-6) + (-9) = -(6 + 9) = -15}\).
{{% /details %}}

> [!IMPORTANT] **Remarque**
>
> Pour éviter que deux signes se suivent, on écrit les nombres négatifs entre parenthèses : \({3 + (-5)}\) et non \({3 + -5}\).

## Deux nombres de signes contraires

> [!TIP] **Définition**
>
> La somme de deux nombres relatifs de **signes contraires** est le nombre qui a :
> - le signe du nombre qui a la plus grande valeur absolue ;
> - pour valeur absolue la **différence** de leurs valeurs absolues (la plus grande moins la plus petite).

{{% details title="Exemple" closed="true" %}}
- \({9 + (-4)}\) : \(9\) a la plus grande valeur absolue, la somme est positive : \({9 + (-4) = 9 - 4 = 5}\).
- \({(-7{,}2) + 3{,}5}\) : \({-7{,}2}\) a la plus grande valeur absolue, la somme est négative : \({(-7{,}2) + 3{,}5 = -(7{,}2 - 3{,}5) = -3{,}7}\).
- \({(-11) + 11 = 0}\) : la somme de deux nombres opposés est nulle.
{{% /details %}}

> [!TIP] **Propriété**
>
> Dans une somme de plusieurs nombres relatifs, on peut modifier l’ordre des termes et regrouper plusieurs termes.

{{% details title="Exemple" closed="true" %}}
\[
A = 8 + (-3) + 4 + (-6) = (8 + 4) + \big((-3) + (-6)\big) = 12 + (-9) = 3.
\]
On a regroupé les nombres positifs entre eux et les nombres négatifs entre eux.
{{% /details %}}

## S’entraîner

> [!NOTE] **Exercice résolu**
>
> Calculer : a) \({(-12) + (-8)}\) ; b) \({15 + (-21)}\) ; c) \({(-2{,}6) + 4}\) ; d) \({B = (-5) + 7 + (-9) + 3}\).

{{% details title="Solution commentée" closed="true" %}}
a) Même signe : \({-20}\). b) Signes contraires, \({21 > 15}\) : \({-6}\). c) Signes contraires, \({4 > 2{,}6}\) : \(1{,}4\).

d) \(B = (7 + 3) + \big((-5) + (-9)\big) = 10 + (-14) = -4\).
{{% /details %}}
