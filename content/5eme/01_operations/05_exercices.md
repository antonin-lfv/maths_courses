### Exercice 1

Calculer en respectant les priorités : \({A = 7 + 3 \times 5}\) ; \({B = (7 + 3) \times 5}\) ; \({C = 40 - 4^2 \div 2}\) ; \({D = \dfrac{25 - 7}{2 + 4}}\).

{{% details title="Solution" closed="true" %}}
\({A = 22}\) ; \({B = 50}\) ; \({C = 40 - 16 \div 2 = 40 - 8 = 32}\) ; \({D = \dfrac{18}{6} = 3}\).
{{% /details %}}

### Exercice 2

Calculer astucieusement : \({48 \times 101}\) ; \({(6{,}3 \times 7) + (6{,}3 \times 3)}\) ; \({15 \div 0{,}25}\).

{{% details title="Solution" closed="true" %}}
\({4\,800 + 48 = 4\,848}\) ; \({6{,}3 \times 10 = 63}\) ; \({\dfrac{1\,500}{25} = 60}\).
{{% /details %}}

### Exercice 3

Le nombre \(7\,236\) est-il divisible par \(2\) ? par \(3\) ? par \(5\) ? par \(9\) ?

{{% details title="Solution" closed="true" %}}
Chiffre des unités \(6\) : divisible par \(2\), pas par \(5\). Somme des chiffres \(18\) : divisible par \(3\) et par \(9\).
{{% /details %}}

### Exercice 4

On note \(n\) un nombre. Traduire par une expression littérale : a) le double de \(n\) augmenté de \(5\) ; b) le carré de \(n\) ; c) le triple de la somme de \(n\) et de \(4\). Calculer chaque expression pour \({n = 3}\).

{{% details title="Solution" closed="true" %}}
a) \({2n + 5}\), qui vaut \(11\) ; b) \(n^2\), qui vaut \(9\) ; c) \({3(n + 4)}\), qui vaut \(21\).
{{% /details %}}
