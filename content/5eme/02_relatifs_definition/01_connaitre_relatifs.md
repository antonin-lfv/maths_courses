## Nombres positifs, nombres négatifs

> [!TIP] **Définitions**
>
> - Un **nombre positif** est un nombre supérieur ou égal à \(0\). On l’écrit avec un signe \(+\) ou sans signe.
> - Un **nombre négatif** est un nombre inférieur ou égal à \(0\). On l’écrit avec un signe \(-\).
> - Les nombres positifs et les nombres négatifs forment l’ensemble des **nombres relatifs**.
> - Un nombre **strictement positif** est un nombre positif non nul ; un nombre **strictement négatif** est un nombre négatif non nul.

{{% details title="Exemple" closed="true" %}}
- Une température de \(-6\) °C est négative ; une altitude de \(+2\,300\) m (ou \(2\,300\) m) est positive.
- \(0\) est le seul nombre à la fois positif et négatif.
- \(-0{,}8\) et \(-150\) sont des nombres relatifs négatifs ; \(4{,}7\) est un nombre relatif positif.
{{% /details %}}

> [!IMPORTANT] **Remarque**
>
> Grâce aux nombres négatifs, on peut effectuer des soustractions qui étaient impossibles jusqu’ici : par exemple, \(5 - 9 = -4\).

## Nombres opposés

> [!TIP] **Définition**
>
> Deux nombres sont **opposés** si leur somme est égale à \(0\).

{{% details title="Exemple" closed="true" %}}
\(-7\) est l’opposé de \(7\), car \(7 + (-7) = 0\). Les nombres \(2{,}5\) et \(-2{,}5\) sont opposés. L’opposé de \(0\) est \(0\).
{{% /details %}}

> [!IMPORTANT] **Remarque**
>
> Deux nombres opposés non nuls sont de signes contraires : l’un est positif, l’autre négatif. Ils ne diffèrent que par leur signe.

## Valeur absolue

> [!TIP] **Définition**
>
> La **valeur absolue** d’un nombre est égale :
> - à ce nombre, s’il est positif ;
> - à l’opposé de ce nombre, s’il est négatif.
>
> On note \(|a|\) la valeur absolue du nombre \(a\).

{{% details title="Exemple" closed="true" %}}
\(|9| = 9\) ; \(|-9| = 9\) ; \(|-0{,}35| = 0{,}35\) ; \(|0| = 0\).
{{% /details %}}

> [!TIP] **Propriétés**
>
> - La valeur absolue d’un nombre est toujours positive.
> - Deux nombres opposés ont la même valeur absolue.

## S’entraîner

> [!NOTE] **Exercice résolu**
>
> On donne les nombres : \(-3{,}5\) ; \(12\) ; \(0\) ; \(-0{,}1\) ; \(+8\).
> 1. Lesquels sont négatifs ? strictement positifs ?
> 2. Donner l’opposé et la valeur absolue de chacun.

{{% details title="Solution commentée" closed="true" %}}
1. Négatifs : \(-3{,}5\), \(0\), \(-0{,}1\). Strictement positifs : \(12\) et \(+8\).
2. Opposés : \(3{,}5\) ; \(-12\) ; \(0\) ; \(0{,}1\) ; \(-8\). Valeurs absolues : \(3{,}5\) ; \(12\) ; \(0\) ; \(0{,}1\) ; \(8\).
{{% /details %}}
