Cours du chapitre 2 : Nombres relatifs (définition).

{{< sommaire >}}

{{% fiche %}}
**Nombres relatifs** - positifs (\({\geq 0}\)), négatifs (\({\leq 0}\)) ; \(0\) est les deux. Opposés : somme nulle, signes contraires. Valeur absolue : le nombre s’il est positif, son opposé s’il est négatif ; toujours positive.

**Repérage** - droite graduée (origine, sens, unité) : abscisse ; points symétriques par rapport à l’origine \({\iff}\) abscisses opposées ; \({|a| = OA}\). Repère du plan : coordonnées (abscisse ; ordonnée), dans cet ordre.

**Comparaison** - un positif est supérieur à un négatif ; entre positifs, la plus grande valeur absolue l’emporte ; entre négatifs, c’est la plus petite valeur absolue qui donne le plus grand nombre.
