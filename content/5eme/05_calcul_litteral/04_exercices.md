### Exercice 1

Simplifier : \(A = 4 \times x \times 3\) ; \(B = y \times y \times 6\) ; \(C = 2 \times a \times 0{,}5\).

{{% details title="Solution" closed="true" %}}
\(A = 12x\) ; \(B = 6y^2\) ; \(C = a\).
{{% /details %}}

### Exercice 2

Développer : \(D = 5(x + 4)\) ; \(E = 3(2a - 7)\). Factoriser puis réduire : \(F = 8t + 3t\) ; \(G = 9x - 2x - x\).

{{% details title="Solution" closed="true" %}}
\(D = 5x + 20\) ; \(E = 6a - 21\) ; \(F = 11t\) ; \(G = 6x\).
{{% /details %}}

### Exercice 3

L’égalité \(x^2 + 1 = 2x\) est-elle vraie pour \(x = 1\) ? pour \(x = 3\) ? Est-elle vraie pour tout nombre \(x\) ?

{{% details title="Solution" closed="true" %}}
Pour \(x = 1\) : \(2 = 2\), vraie. Pour \(x = 3\) : \(10\) et \(6\), fausse. Elle n’est donc pas vraie pour tout \(x\) (contre-exemple : \(x = 3\)).
{{% /details %}}

### Exercice 4

Résoudre : a) \(x - 12 = 30\) ; b) \(5x = 42\) ; c) \(3x - 4 = 11\).

{{% details title="Solution" closed="true" %}}
a) \(x = 42\) ; b) \(x = 8{,}4\) ; c) \(3x = 15\), \(x = 5\).
{{% /details %}}

### Exercice 5

Le périmètre d’un rectangle est \(38\) cm et sa largeur est \(7\) cm. On note \(L\) sa longueur. Écrire une équation, puis la résoudre.

{{% details title="Solution" closed="true" %}}
\(2L + 2 \times 7 = 38\), soit \(2L + 14 = 38\). Donc \(2L = 24\) et \(L = 12\) cm.
{{% /details %}}
