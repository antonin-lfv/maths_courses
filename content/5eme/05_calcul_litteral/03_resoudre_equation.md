## Équation et solution

> [!TIP] **Définitions**
>
> - Une **équation** est une égalité qui comporte au moins un nombre de valeur inconnue, généralement désigné par une lettre (l’**inconnue**). Cette égalité peut être vraie pour certaines valeurs de l’inconnue et fausse pour d’autres.
> - Une **solution** d’une équation est une valeur de l’inconnue pour laquelle l’égalité est vraie.
> - **Résoudre une équation**, c’est trouver toutes les solutions de cette équation.

{{% details title="Exemple" closed="true" %}}
On considère l’équation \(x + 6 = 10\) d’inconnue \(x\).
- Si \(x = 4\) : \(4 + 6 = 10\), l’égalité est vraie : \(4\) est une solution.
- Si \(x = 3\) : \(3 + 6 = 9 \neq 10\), l’égalité est fausse : \(3\) n’est pas une solution.
{{% /details %}}

## Transformer une équation

> [!TIP] **Propriété**
>
> Une équation garde les mêmes solutions lorsqu’on **ajoute** (ou qu’on **soustrait**) un même nombre à chacun de ses membres.

{{% details title="Exemple" closed="true" %}}
On résout \(x - 7 = 5\). On ajoute \(7\) à chacun des membres : \(x - 7 + 7 = 5 + 7\), donc \(x = 12\).

Vérification : \(12 - 7 = 5\). La solution est \(12\).
{{% /details %}}

> [!TIP] **Propriété**
>
> Une équation garde les mêmes solutions lorsqu’on **multiplie** (ou qu’on **divise**) ses deux membres par un même nombre **non nul**.

{{% details title="Exemple" closed="true" %}}
On résout \(6x = 15\). On divise les deux membres par \(6\) : \(\dfrac{6x}{6} = \dfrac{15}{6}\), donc \(x = 2{,}5\).

Vérification : \(6 \times 2{,}5 = 15\). La solution est \(2{,}5\).
{{% /details %}}

## S’entraîner

> [!NOTE] **Exercice résolu**
>
> Résoudre : a) \(x + 3{,}5 = 9\) ; b) \(4x = 26\) ; c) \(2x + 5 = 17\).

{{% details title="Solution commentée" closed="true" %}}
a) On soustrait \(3{,}5\) : \(x = 9 - 3{,}5 = 5{,}5\).

b) On divise par \(4\) : \(x = \dfrac{26}{4} = 6{,}5\).

c) On soustrait \(5\) : \(2x = 12\) ; puis on divise par \(2\) : \(x = 6\). Vérification : \(2 \times 6 + 5 = 17\).
{{% /details %}}

> [!NOTE] **Exercice résolu**
>
> Léa pense à un nombre. Elle le multiplie par \(3\), puis ajoute \(8\). Elle obtient \(29\). Quel est ce nombre ?

{{% details title="Solution commentée" closed="true" %}}
On note \(x\) le nombre. On obtient l’équation \(3x + 8 = 29\). En soustrayant \(8\) : \(3x = 21\) ; en divisant par \(3\) : \(x = 7\). Vérification : \(3 \times 7 + 8 = 29\). Léa pensait au nombre \(7\).
{{% /details %}}
