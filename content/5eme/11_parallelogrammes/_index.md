Cours du chapitre 11 : Parallélogrammes.

{{< sommaire >}}

{{% fiche %}}
**Parallélogramme** - côtés opposés parallèles ; diagonales de même milieu (centre de symétrie) ; côtés opposés de même longueur ; angles opposés égaux.

**Le reconnaître** - diagonales de même milieu ; ou côtés opposés deux à deux égaux (non croisé) ; ou deux côtés opposés parallèles et de même longueur.

**Particuliers** - losange : quatre côtés égaux, diagonales perpendiculaires ; rectangle : quatre angles droits, diagonales de même longueur ; carré : les deux.

**Aires** - \(1\) m² \({= 100}\) dm² ; parallélogramme : base \({\times}\) hauteur ; figures complexes : décomposer, compléter, découper.
