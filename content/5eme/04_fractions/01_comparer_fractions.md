## Quotient et fraction

> [!TIP] **Définition**
>
> \(a\) et \(b\) désignent deux nombres (\({b \neq 0}\)). Le **quotient** de \(a\) par \(b\) est le nombre qui, multiplié par \(b\), donne \(a\). On le note \(\dfrac{a}{b}\). Si \(a\) et \(b\) sont des entiers, on dit que \(\dfrac{a}{b}\) est une **fraction**.

{{% details title="Exemple" closed="true" %}}
\(\dfrac{8}{3}\) est le nombre qui, multiplié par \(3\), donne \(8\) : \({\dfrac{8}{3} \times 3 = 8}\).
{{% /details %}}

## Fractions égales

> [!TIP] **Propriété**
>
> \(a\), \(b\) et \(k\) désignent trois nombres (\({b \neq 0}\) et \({k \neq 0}\)). Un quotient ne change pas si l’on multiplie (ou si l’on divise) son numérateur et son dénominateur par un même nombre non nul :
> \[
\dfrac{a}{b} = \dfrac{a \times k}{b \times k} = \dfrac{a \div k}{b \div k}.
\]

{{% details title="Exemple" closed="true" %}}
\({\dfrac{1{,}5}{4} = \dfrac{1{,}5 \times 2}{4 \times 2} = \dfrac{3}{8}}\) : on obtient une fraction. \({\dfrac{28}{35} = \dfrac{28 \div 7}{35 \div 7} = \dfrac{4}{5}}\) : on a simplifié.
{{% /details %}}

## Comparer

> [!TIP] **Propriétés**
>
> - Pour comparer deux fractions qui ont le même dénominateur positif, on compare leurs numérateurs : la plus grande est celle qui a le plus grand numérateur.
> - Pour comparer deux fractions de dénominateurs différents, on peut d’abord les écrire avec le même dénominateur.

{{% details title="Exemple" closed="true" %}}
- \({\dfrac{4}{9} < \dfrac{7}{9}}\) car \({4 < 7}\).
- Pour comparer \(\dfrac{5}{4}\) et \(\dfrac{11}{8}\) : \({\dfrac{5}{4} = \dfrac{10}{8}}\), et \({10 < 11}\), donc \({\dfrac{5}{4} < \dfrac{11}{8}}\).
{{% /details %}}

> [!TIP] **Propriété - Comparer à 1**
>
> \(a\) et \(b\) désignent deux nombres positifs (\({b \neq 0}\)) :
> - si \({a > b}\), alors \({\dfrac{a}{b} > 1}\) ;
> - si \({a < b}\), alors \({\dfrac{a}{b} < 1}\) ;
> - si \({a = b}\), alors \({\dfrac{a}{b} = 1}\).

{{% details title="Exemple" closed="true" %}}
Pour comparer \(\dfrac{6}{7}\) et \(\dfrac{10}{9}\) : \({6 < 7}\), donc \({\dfrac{6}{7} < 1}\) ; \({10 > 9}\), donc \({\dfrac{10}{9} > 1}\). Ainsi \({\dfrac{6}{7} < 1 < \dfrac{10}{9}}\).
{{% /details %}}

## S’entraîner

> [!NOTE] **Exercice résolu**
>
> Ranger dans l’ordre croissant : \(\dfrac{2}{3}\) ; \(\dfrac{5}{6}\) ; \(\dfrac{7}{12}\) ; \(\dfrac{13}{12}\).

{{% details title="Solution commentée" closed="true" %}}
On écrit toutes les fractions avec le dénominateur \(12\) : \(\dfrac{8}{12}\) ; \(\dfrac{10}{12}\) ; \(\dfrac{7}{12}\) ; \(\dfrac{13}{12}\). Ordre croissant : \({\dfrac{7}{12} < \dfrac{2}{3} < \dfrac{5}{6} < \dfrac{13}{12}}\).
{{% /details %}}
