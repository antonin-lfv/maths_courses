#### Fiche résumé du chapitre

**Quotient** — \(\frac{a}{b} \times b = a\) ; \(\frac{a}{b} = \frac{a \times k}{b \times k}\) (\(k \neq 0\)).

**Comparer** — même dénominateur : comparer les numérateurs ; sinon, réduire au même dénominateur ; comparer à \(1\).

**Additionner, soustraire** — même dénominateur : \(\frac{a}{c} \pm \frac{b}{c} = \frac{a \pm b}{c}\) ; sinon, réduire au même dénominateur ; schéma en barres pour les problèmes.

**Proportions** — \(\frac{a}{b} \times c = \frac{a \times c}{b}\) ; fraction d’une quantité : multiplier ; pourcentage : dénominateur \(100\) ; \(t\,\%\) d’une quantité : \(\frac{t}{100} \times\) quantité.
