#### Fiche résumé du chapitre

**Quotient** - \({\dfrac{a}{b} \times b = a}\) ; \({\dfrac{a}{b} = \dfrac{a \times k}{b \times k}}\) (\({k \neq 0}\)).

**Comparer** - même dénominateur : comparer les numérateurs ; sinon, réduire au même dénominateur ; comparer à \(1\).

**Additionner, soustraire** - même dénominateur : \({\dfrac{a}{c} \pm \dfrac{b}{c} = \dfrac{a \pm b}{c}}\) ; sinon, réduire au même dénominateur ; schéma en barres pour les problèmes.

**Proportions** - \({\dfrac{a}{b} \times c = \dfrac{a \times c}{b}}\) ; fraction d’une quantité : multiplier ; pourcentage : dénominateur \(100\) ; \(t\,\%\) d’une quantité : \({\dfrac{t}{100} \times}\) quantité.
