### Exercice 1

Compléter : \({\dfrac{3}{5} = \dfrac{\dots}{40}}\) ; \({\dfrac{2{,}4}{3} = \dfrac{24}{\dots}}\) ; \({\dfrac{45}{60} = \dfrac{3}{\dots}}\).

{{% details title="Solution" closed="true" %}}
\(\dfrac{24}{40}\) ; \(\dfrac{24}{30}\) ; \(\dfrac{3}{4}\).
{{% /details %}}

### Exercice 2

Comparer : a) \(\dfrac{7}{10}\) et \(\dfrac{3}{5}\) ; b) \(\dfrac{9}{8}\) et \(\dfrac{8}{9}\) ; c) \(\dfrac{5}{3}\) et \(\dfrac{17}{9}\).

{{% details title="Solution" closed="true" %}}
a) \({\dfrac{3}{5} = \dfrac{6}{10} < \dfrac{7}{10}}\). b) \({\dfrac{9}{8} > 1 > \dfrac{8}{9}}\). c) \({\dfrac{5}{3} = \dfrac{15}{9} < \dfrac{17}{9}}\).
{{% /details %}}

### Exercice 3

Calculer : a) \({\dfrac{2}{7} + \dfrac{4}{7}}\) ; b) \({\dfrac{5}{12} + \dfrac{1}{3}}\) ; c) \({\dfrac{9}{10} - \dfrac{2}{5}}\) ; d) \({2 + \dfrac{3}{4}}\).

{{% details title="Solution" closed="true" %}}
a) \(\dfrac{6}{7}\) ; b) \({\dfrac{5}{12} + \dfrac{4}{12} = \dfrac{9}{12} = \dfrac{3}{4}}\) ; c) \({\dfrac{9}{10} - \dfrac{4}{10} = \dfrac{5}{10} = \dfrac{1}{2}}\) ; d) \({\dfrac{8}{4} + \dfrac{3}{4} = \dfrac{11}{4}}\).
{{% /details %}}

### Exercice 4

Un réservoir de \(60\) L contient de l’eau aux \(\dfrac{2}{5}\) de sa capacité. On ajoute \(\dfrac{1}{4}\) de la capacité. Quelle fraction du réservoir est remplie ? Combien de litres cela représente-t-il ?

{{% details title="Solution" closed="true" %}}
\({\dfrac{2}{5} + \dfrac{1}{4} = \dfrac{8}{20} + \dfrac{5}{20} = \dfrac{13}{20}}\). \({\dfrac{13}{20} \times 60 = 13 \times 3 = 39}\) L.
{{% /details %}}

### Exercice 5

Dans un collège de \(650\) élèves, \(208\) déjeunent à la cantine. Exprimer cette proportion en pourcentage.

{{% details title="Solution" closed="true" %}}
\({\dfrac{208}{650} = 0{,}32 = \dfrac{32}{100}}\), soit \(32\,\%\).
{{% /details %}}
