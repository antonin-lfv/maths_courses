#### Fiche résumé du chapitre

**Racine carrée** - définie sur \({[0\,;\,+\infty[}\), strictement croissante : \({0 \leq a < b \iff \sqrt{a} < \sqrt{b}}\). Courbe symétrique de la demi-parabole \({y = x^2}\) (\({x \geq 0}\)) par rapport à \({y = x}\).

**Positions** - si \({0 < x < 1}\) : \({x^2 < x < \sqrt{x}}\) ; si \({x > 1}\) : \({\sqrt{x} < x < x^2}\).

**Inverse** - définie sur \(\mathbb{R}^*\), hyperbole symétrique par rapport à l’origine ; strictement décroissante sur \({]-\infty\,;\,0[}\) et sur \({]0\,;\,+\infty[}\) (pas sur \(\mathbb{R}^*\)) : pour \(a\), \(b\) de même signe, \({a < b \iff \dfrac{1}{a} > \dfrac{1}{b}}\).

**Équations** - \({\sqrt{x} = c}\) : \({x = c^2}\) si \({c \geq 0}\), aucune solution sinon. \({\dfrac{1}{x} = c}\) : \({x = \dfrac{1}{c}}\) si \({c \neq 0}\), aucune solution si \({c = 0}\).

**Inéquations** - \({\sqrt{x} < c \iff 0 \leq x < c^2}\) (\({c > 0}\)). \({\dfrac{1}{x} < c}\) (\({c > 0}\)) \({\iff x < 0}\) ou \({x > \dfrac{1}{c}}\) ; en cas de doute, tableau de signes de \({\dfrac{1 - cx}{x}}\).
