#### Fiche résumé du chapitre

**Proportion** - \({p = \dfrac{n_A}{n_E}}\) et \({n_A = p \times n_E}\) ; \({p(\overline{A}) = 1 - p(A)}\) ; \({p(A \cup B) = p(A) + p(B) - p(A \cap B)}\) ; proportion de proportion : \({p \times p'}\).

**Évolution** - variation absolue \({V_1 - V_0}\) ; taux \({t = \dfrac{V_1 - V_0}{V_0}}\) ; \({V_1 = (1 + t)V_0}\), \({CM = 1 + t}\) (hausse si \({CM > 1}\), baisse si \({CM < 1}\)).

**Évolutions successives et réciproque** - \({CM_G = CM_1 \times CM_2}\), les taux ne s’additionnent pas ; réciproque : \({CM' = \dfrac{1}{CM}}\).

**Indicateurs de position et de dispersion** - moyenne \({\bar{x} = \dfrac{\sum n_ix_i}{N}}\) (linéaire) ; variance \({V = \dfrac{\sum n_i(x_i - \bar{x})^2}{N}}\), écart type \({\sigma = \sqrt{V}}\) ; médiane, quartiles \(Q_1\) et \(Q_3\) (avec les effectifs cumulés), écart interquartile \({Q_3 - Q_1}\). Couples \((\bar{x}\,;\,\sigma)\) et \({(\text{Méd}\,;\,Q_3 - Q_1)}\).
