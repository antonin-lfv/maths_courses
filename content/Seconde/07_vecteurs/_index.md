#### Fiche résumé du chapitre

**Vecteur** — \(\overrightarrow{AB}\) : direction \((AB)\), sens de \(A\) vers \(B\), norme \(AB\). \(\overrightarrow{AB} = \overrightarrow{CD} \iff ABDC\) parallélogramme \(\iff [AD]\) et \([BC]\) ont le même milieu. \(\overrightarrow{AB} = \vec{0} \iff A = B\).

**Opérations** — Chasles : \(\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}\) ; parallélogramme : \(ABCD\) parallélogramme \(\iff \overrightarrow{AB} + \overrightarrow{AD} = \overrightarrow{AC}\) ; \(-\overrightarrow{AB} = \overrightarrow{BA}\) ; \(k\vec{u}\) : même direction, sens selon le signe de \(k\), norme \(|k|\,\|\vec{u}\|\).

**Milieu** — \(M\) milieu de \([AB] \iff \overrightarrow{AM} = \overrightarrow{MB} \iff \overrightarrow{MA} + \overrightarrow{MB} = \vec{0} \iff \overrightarrow{AM} = \frac{1}{2}\overrightarrow{AB}\).

**Coordonnées** — \(\vec{u} = x\vec{i} + y\vec{j}\) ; \(\overrightarrow{AB}\begin{pmatrix} x_B - x_A \\ y_B - y_A \end{pmatrix}\) ; milieu \(\left(\frac{x_A + x_B}{2}\,;\,\frac{y_A + y_B}{2}\right)\) ; opérations coordonnée par coordonnée.

**Repère orthonormé** — \(\|\vec{u}\| = \sqrt{x^2 + y^2}\) ; \(AB = \sqrt{(x_B - x_A)^2 + (y_B - y_A)^2}\).
