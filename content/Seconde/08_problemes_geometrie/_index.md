Cours du chapitre 8 : Problèmes de géométrie.

{{< sommaire >}}

{{% fiche %}}
**Colinéarité** - \(\vec{u}\), \(\vec{v}\) colinéaires s’il existe \(k\) tel que \({\vec{v} = k\vec{u}}\) ; \({\det(\vec{u}, \vec{v}) = xy' - x'y}\) ; colinéaires \({\iff \det = 0}\). Deux vecteurs non colinéaires forment une base.

**Parallélisme et alignement** - \({(AB) \parallel (CD) \iff \overrightarrow{AB}}\), \(\overrightarrow{CD}\) colinéaires ; \(A\), \(B\), \(C\) alignés \({\iff \overrightarrow{AB}}\), \(\overrightarrow{AC}\) colinéaires. Sans repère : relation de Chasles et décomposition dans une base.

**Homothétie** - de centre \(H\), de rapport \(k\) : \({\overrightarrow{HM'} = k\overrightarrow{HM}}\).

**Triangle rectangle** - \({\cos^2 \alpha + \sin^2 \alpha = 1}\) ; le centre du cercle circonscrit est le milieu de l’hypoténuse ; un triangle inscrit dans un cercle ayant un côté pour diamètre est rectangle.

**Projeté orthogonal** - pied de la perpendiculaire ; c’est le point de la droite le plus proche de \(M\) ; \(MH\) est la distance de \(M\) à la droite. Thalès : \({\dfrac{AB}{AC} = \dfrac{A'B'}{A'C'}}\) pour des projetés orthogonaux.
