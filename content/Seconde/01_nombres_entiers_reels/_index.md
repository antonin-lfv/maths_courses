#### Fiche résumé du chapitre

**Divisibilité** — \(b\) divise \(a\) s’il existe \(k \in \mathbb{Z}\) tel que \(a = kb\). La somme de deux multiples de \(b\) est un multiple de \(b\). \(n\) pair : \(n = 2k\) ; impair : \(n = 2k + 1\). Le carré d’un impair est impair.

**Nombres premiers** — exactement deux diviseurs positifs (\(1\) et lui-même) ; \(1\) n’est pas premier, \(2\) est le seul premier pair. Tout entier \(\geq 2\) se décompose de façon unique en produit de facteurs premiers.

**Ensembles** — \(\mathbb{N} \subset \mathbb{Z} \subset \mathbb{D} \subset \mathbb{Q} \subset \mathbb{R}\) ; décimal : \(\frac{a}{10^n}\) ; rationnel : \(\frac{p}{q}\). \(\frac{1}{3} \notin \mathbb{D}\), \(\sqrt{2} \notin \mathbb{Q}\).

**Intervalles** — \([a\,;\,b]\), \(]a\,;\,b[\), \([a\,;\,+\infty[\)… ; crochet ouvert du côté de \(\pm\infty\). \(I \cap J\) : dans les deux ; \(I \cup J\) : dans l’un au moins.

**Valeur absolue** — \(|x| = x\) si \(x \geq 0\), \(-x\) sinon ; distance entre \(a\) et \(b\) : \(|a - b|\). \(|x - a| \leq r \iff x \in [a - r\,;\,a + r]\).

**Puissances** — \(a^m a^n = a^{m+n}\), \(\frac{a^m}{a^n} = a^{m-n}\), \((a^m)^n = a^{mn}\), \(a^{-n} = \frac{1}{a^n}\) ; écriture scientifique \(a \times 10^n\), \(1 \leq |a| < 10\).

**Racines carrées** — \(\sqrt{x} \geq 0\) et \((\sqrt{x})^2 = x\) pour \(x \geq 0\) ; \(\sqrt{x^2} = |x|\) ; \(\sqrt{ab} = \sqrt{a}\sqrt{b}\) ; \(\sqrt{a + b} < \sqrt{a} + \sqrt{b}\) pour \(a, b > 0\).
