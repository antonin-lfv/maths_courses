Cours du chapitre 4 : Fonctions carré et cube.

{{% fiche %}}
**Fonction carré** - parabole de sommet \(O\), symétrique par rapport à l’axe des ordonnées ; décroissante sur \({]-\infty\,;\,0]}\), croissante sur \({[0\,;\,+\infty[}\), minimum \(0\) en \(0\). Positifs : même ordre que les carrés ; négatifs : ordre inversé.

**Fonction cube** - courbe symétrique par rapport à l’origine ; strictement croissante sur \(\mathbb{R}\) : \({a < b \iff a^3 < b^3}\).

**Positions** - si \({0 < x < 1}\) : \({x^3 < x^2 < x}\) ; si \({x > 1}\) : \({x < x^2 < x^3}\).

**Équations** - \({x^2 = c}\) : aucune solution si \({c < 0}\), \(0\) si \({c = 0}\), \({\pm\sqrt{c}}\) si \({c > 0}\). \({x^3 = c}\) : une seule solution \(\sqrt[3]{c}\).

**Inéquations** - \({x^2 < c \iff x \in ]-\sqrt{c}\,;\,\sqrt{c}[}\) (\({c > 0}\)) ; \({x^3 < c \iff x < \sqrt[3]{c}}\).

**Tableaux de signes** - une ligne par facteur affine, règle des signes ; un quotient a le signe du produit, double barre aux valeurs interdites. Toujours comparer à \(0\) avant de factoriser.
