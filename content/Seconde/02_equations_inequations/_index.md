#### Fiche résumé du chapitre

**Fractions** - \({\dfrac{a}{b} = \dfrac{c}{d} \iff ad = bc}\) ; \({\dfrac{a}{b} \times \dfrac{c}{d} = \dfrac{ac}{bd}}\) ; diviser par \(\dfrac{c}{d}\) revient à multiplier par \(\dfrac{d}{c}\) ; on ne simplifie que par un facteur commun.

**Identités remarquables** - \({(a + b)^2 = a^2 + 2ab + b^2}\) ; \({(a - b)^2 = a^2 - 2ab + b^2}\) ; \({(a + b)(a - b) = a^2 - b^2}\).

**Équations** - on garde une équation équivalente en ajoutant une même quantité aux deux membres ou en les multipliant par un nombre non nul. Produit nul : \({AB = 0 \iff A = 0}\) ou \({B = 0}\). Quotient nul : \({\dfrac{A}{B} = 0 \iff A = 0}\) et \({B \neq 0}\) ; penser aux valeurs interdites.

**Inégalités** - \({a < b \iff b - a > 0}\) ; multiplier par un nombre strictement négatif change le sens ; on peut ajouter membre à membre deux inégalités de même sens, pas les soustraire.

**Inéquations du premier degré** - mêmes règles que les équations, en changeant le sens si on multiplie ou divise par un nombre négatif ; l’ensemble des solutions est un intervalle.
