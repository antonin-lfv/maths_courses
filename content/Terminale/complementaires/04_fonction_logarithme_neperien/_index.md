#### Fiche résumé du chapitre

**Fonction réciproque** - \(f\) continue strictement monotone de \(I\) sur \(J\) : \({f^{-1}}\) associe à \({y \in J}\) l’unique \({x \in I}\) tel que \({f(x) = y}\) ; courbes symétriques par rapport à \({y = x}\).

**Définition de \(\ln\)** - réciproque de l’exponentielle : pour \({y > 0}\), \({e^x = y \iff x = \ln(y)}\) ; \({e^{\ln x} = x}\) (\({x > 0}\)), \({\ln(e^x) = x}\) ; \({\ln 1 = 0}\), \({\ln e = 1}\).

**Relations fonctionnelles** (\({a, b > 0}\)) - \({\ln(ab) = \ln a + \ln b}\), \({\ln\dfrac{1}{a} = -\ln a}\), \({\ln\dfrac{a}{b} = \ln a - \ln b}\), \({\ln(a^n) = n\ln a}\), \({\ln\sqrt{a} = \dfrac{1}{2}\ln a}\).

**Étude** - \({\ln' (x) = \dfrac{1}{x}}\), \(\ln\) strictement croissante sur \({]0\,;\,+\infty[}\) ; \({\ln a < \ln b \iff a < b}\) ; \({\ln a > 0 \iff a > 1}\). Tangente en 1 : \({y = x - 1}\).

**Limites** - \({\lim\limits_{+\infty} \ln = +\infty}\), \({\lim\limits_{0} \ln = -\infty}\), \({\lim\limits_{0} \dfrac{\ln(1 + x)}{x} = 1}\), \({\lim\limits_{0} x\ln x = 0}\), \({\lim\limits_{+\infty} \dfrac{\ln x}{x} = 0}\).

**Dérivée** - \({(\ln u)' = \dfrac{u'}{u}}\) pour \({u > 0}\).
