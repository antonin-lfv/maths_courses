#### Fiche résumé du chapitre

**Nombre dérivé** — \(f'(a) = \lim\limits_{h \to 0} \frac{f(a + h) - f(a)}{h}\) ; tangente au point d’abscisse \(a\) : \(y = f'(a)(x - a) + f(a)\). Dérivable \(\Rightarrow\) continue (réciproque fausse : \(|x|\) en 0).

**Variations** — \(f' > 0\) sur \(I\) : \(f\) strictement croissante ; \(f' < 0\) : strictement décroissante ; \(f' = 0\) : constante. Extremum local en \(a\) (intérieur à \(I\)) \(\Rightarrow f'(a) = 0\) ; si \(f'\) s’annule en changeant de signe, il y a un extremum.

**Dérivées usuelles** — \((x^n)' = nx^{n-1}\), \(\left(\frac{1}{x}\right)' = -\frac{1}{x^2}\), \((\sqrt{x})' = \frac{1}{2\sqrt{x}}\), \((e^x)' = e^x\).

**Opérations** — \((uv)' = u'v + uv'\), \(\left(\frac{1}{u}\right)' = -\frac{u'}{u^2}\), \(\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}\).

**Composées** — \((e^u)' = u'e^u\), \((u^2)' = 2u'u\), \((\sqrt{u})' = \frac{u'}{2\sqrt{u}}\) (\(u > 0\)), \(\left(f(ax + b)\right)' = af'(ax + b)\).
