Cours du chapitre 1 : Suites et limites.

{{< sommaire >}}

{{% fiche %}}
**Limites de référence** - \(\dfrac{1}{n}\), \(\dfrac{1}{n^k}\), \(\dfrac{1}{\sqrt{n}}\) tendent vers 0 ; \(n\), \(n^k\), \(\sqrt{n}\) tendent vers \({+\infty}\). Une suite peut n’avoir aucune limite (\({(-1)^n}\)).

**Opérations** - tableaux de la somme, du produit et du quotient ; formes indéterminées : \({\infty - \infty}\), \({0 \times \infty}\), \(\dfrac{\infty}{\infty}\), \(\dfrac{0}{0}\) (on factorise par le terme dominant).

**Comparaison** - si \({u_n \leq v_n}\) et \({u_n \to +\infty}\), alors \({v_n \to +\infty}\) ; si \({v_n \to -\infty}\), alors \({u_n \to -\infty}\). Les inégalités larges passent à la limite. Gendarmes : \({u_n \leq v_n \leq w_n}\), \({u_n \to \ell}\), \({w_n \to \ell}\) \({\Rightarrow}\) \({v_n \to \ell}\).

**Suites de référence** - arithmétique : limite \({\pm\infty}\) selon le signe de \(r\) ; \({q^n \to 0}\) si \({0 \leq q < 1}\), \({\to +\infty}\) si \({q > 1}\) ; si \({0 < q < 1}\), \({u_0 + \dots + u_n \to \dfrac{u_0}{1 - q}}\).

**Arithmético-géométrique** \({u_{n+1} = au_n + b}\) (\({a \neq 1}\)) - \({\ell = a\ell + b}\), \({v_n = u_n - \ell}\) est géométrique de raison \(a\), \({u_n = \ell + (u_0 - \ell)a^n}\).
