#### Fiche résumé du chapitre

**Convexe / concave** - convexe : courbe sous ses sécantes (au-dessus de ses tangentes) ; concave : courbe au-dessus de ses sécantes (sous ses tangentes).

**Fonctions de référence** - \(x^2\) et \(e^x\) convexes sur \(\mathbb{R}\) ; \(\sqrt{x}\) et \(\ln\) concaves ; \(\dfrac{1}{x}\) concave sur \({]-\infty\,;\,0[}\), convexe sur \({]0\,;\,+\infty[}\) ; \(x^3\) concave sur \({]-\infty\,;\,0]}\), convexe sur \({[0\,;\,+\infty[}\).

**Dérivée seconde** - \(f\) convexe sur \(I\) \({\iff f'' \geq 0 \iff f'}\) croissante ; concave \({\iff f'' \leq 0 \iff f'}\) décroissante.

**Point d’inflexion** - la courbe traverse sa tangente ; la fonction change de convexité ; c’est le cas si \(f''\) s’annule **en changeant de signe** (\({f''(a) = 0}\) ne suffit pas).

**Inégalités** - \({e^x \geq x + 1}\) pour tout \(x\) ; \({\ln x \leq x - 1}\) pour \({x > 0}\).
