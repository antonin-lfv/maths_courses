Cours du chapitre 6 : Fonction logarithme.

{{< sommaire >}}

{{% fiche %}}
**Définition** - pour \({a > 0}\), \(\ln(a)\) est l’unique solution de \({e^x = a}\). Pour \({x > 0}\) et \(y\) réel : \({y = \ln(x) \iff e^y = x}\) ; \({\ln(e^x) = x}\), \({e^{\ln x} = x}\) ; \({\ln 1 = 0}\), \({\ln e = 1}\). Les courbes de \(\ln\) et \(\exp\) sont symétriques par rapport à \({y = x}\).

**Relations fonctionnelles** - pour \({x, y > 0}\) et \({n \in \mathbb{Z}}\) : \({\ln(xy) = \ln x + \ln y}\), \({\ln\dfrac{x}{y} = \ln x - \ln y}\), \({\ln\dfrac{1}{y} = -\ln y}\), \({\ln\sqrt{x} = \dfrac12 \ln x}\), \({\ln(x^n) = n\ln x}\).

**Étude** - \({\ln' (x)= \dfrac{1}{x}}\) : \(\ln\) est strictement croissante et concave sur \({]0 ; +\infty[}\) ; \({\ln a = \ln b \iff a = b}\), \({\ln a < \ln b \iff a < b}\) ; \({\ln x < 0}\) sur \(]0 ; 1[\), \({> 0}\) sur \({]1 ; +\infty[}\) ; \({\ln x \leq x - 1}\).

**Limites** - \({\lim\limits_{0^+} \ln x = -\infty}\) (asymptote verticale \({x = 0}\)), \({\lim\limits_{+\infty} \ln x = +\infty}\) ; croissances comparées (\({n \geq 1}\)) : \({\dfrac{\ln x}{x^n} \to 0}\) en \({+\infty}\), \({x^n \ln x \to 0}\) en \({0^+}\) ; \({\lim\limits_{h \to 0} \dfrac{\ln(1+h)}{h} = 1}\).

**Composée** - si \({u > 0}\) est dérivable, \({(\ln u)' = \dfrac{u'}{u}}\), et \(\ln u\) a les mêmes variations que \(u\).
