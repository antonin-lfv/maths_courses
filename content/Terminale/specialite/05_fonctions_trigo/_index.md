#### Fiche résumé du chapitre

**Définitions** - \(\cos\) et \(\sin\) sont définies sur \(\mathbb{R}\), à valeurs dans \({[-1 ; 1]}\), et \({\cos^2 x + \sin^2 x = 1}\).

**Dérivées** - \({\cos' = -\sin}\) et \({\sin' = \cos}\) ; \({(\cos(ax+b))' = -a\sin(ax+b)}\) et \({(\sin(ax+b))' = a\cos(ax+b)}\) ; \({(\cos u)' = -u'\sin u}\) et \({(\sin u)' = u'\cos u}\).

**Limites** - pas de limite en \({\pm\infty}\) ; \({\lim\limits_{x \to 0} \dfrac{\sin x}{x} = 1}\) et \({\lim\limits_{x \to 0} \dfrac{\cos x - 1}{x} = 0}\).

**Parité et périodicité** - \(\cos\) est paire, \(\sin\) est impaire, et toutes deux sont \(2\pi\)-périodiques : une étude sur un intervalle de longueur \(2\pi\) suffit.

**Angles associés** - \({\cos(\pi - t) = -\cos t}\), \({\sin(\pi - t) = \sin t}\), \({\cos(\pi + t) = -\cos t}\), \({\sin(\pi + t) = -\sin t}\), \({\cos\left(\dfrac{\pi}{2} - t\right) = \sin t}\), \({\sin\left(\dfrac{\pi}{2} - t\right) = \cos t}\).

**Équations** - \({\cos x = \cos\alpha \iff x = \pm\alpha + 2k\pi}\) ; \({\sin x = \sin\alpha \iff x = \alpha + 2k\pi}\) ou \({x = \pi - \alpha + 2k\pi}\) (\({k \in \mathbb{Z}}\)).

**Fonctions sinusoïdales** - \({t \mapsto A\cos(\omega t + \varphi)}\) ou \({A\sin(\omega t + \varphi)}\) (\({A, \omega > 0}\)) : amplitude \(A\), période \({T = \dfrac{2\pi}{\omega}}\), fréquence \(\dfrac{1}{T}\).

**Variations sur \({[-\pi ; \pi]}\)** - \(\cos\) croît de \({-1}\) à 1 sur \({[-\pi ; 0]}\), puis décroît jusqu’à \({-1}\) sur \([0 ; \pi]\) ; \(\sin\) décroît de 0 à \({-1}\) sur \({\left[-\pi ; -\dfrac{\pi}{2}\right]}\), croît jusqu’à 1 sur \({\left[-\dfrac{\pi}{2} ; \dfrac{\pi}{2}\right]}\), puis décroît jusqu’à 0 sur \(\left[\dfrac{\pi}{2} ; \pi\right]\).
