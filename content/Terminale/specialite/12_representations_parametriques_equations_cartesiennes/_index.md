#### Fiche résumé du chapitre

**Droite** — passant par \(A(x_A ; y_A ; z_A)\) et dirigée par \(\vec{u}(a ; b ; c)\) : \(x = x_A + at\), \(y = y_A + bt\), \(z = z_A + ct\), \(t \in \mathbb{R}\). Un point est sur la droite si un **même** \(t\) convient pour les trois coordonnées.

**Plan** — de vecteur normal \(\vec{n}(a ; b ; c)\) : équation \(ax + by + cz + k = 0\) ; réciproquement, une telle équation (\(a, b, c\) non tous nuls) définit un plan de vecteur normal \(\vec{n}\). Deux plans sont parallèles si leurs vecteurs normaux sont colinéaires, perpendiculaires si leur produit scalaire est nul.

**Intersections et projetés** — droite \(\cap\) plan : on remplace la représentation paramétrique dans l’équation. Projeté sur un plan : intersection avec la droite passant par \(A\) dirigée par \(\vec{n}\). Projeté sur une droite : intersection avec le plan passant par \(A\) de vecteur normal \(\vec{u}\).
