#### Fiche résumé du chapitre

**Addition** - \({\cos(a \pm b) = \cos a\cos b \mp \sin a\sin b}\) ; \({\sin(a \pm b) = \sin a\cos b \pm \cos a\sin b}\).

**Duplication** - \({\sin 2a = 2\sin a\cos a}\) ; \(\cos 2a = \cos^2 a - \sin^2 a = 2\cos^2 a - 1 = 1 - 2\sin^2 a\) ; \({\cos^2 a = \dfrac{1 + \cos 2a}{2}}\), \({\sin^2 a = \dfrac{1 - \cos 2a}{2}}\).

**Exponentielle** - \({e^{i\theta} = \cos\theta + i\sin\theta}\) (module 1, argument \(\theta\)) ; \({e^{i\theta}e^{i\theta'} = e^{i(\theta + \theta')}}\), \({\left(e^{i\theta}\right)^n = e^{in\theta}}\), \({\overline{e^{i\theta}} = \dfrac{1}{e^{i\theta}} = e^{-i\theta}}\) ; forme exponentielle \({z = re^{i\theta}}\), \({r = |z| > 0}\).

**Euler** - \({\cos\theta = \dfrac{e^{i\theta} + e^{-i\theta}}{2}}\), \({\sin\theta = \dfrac{e^{i\theta} - e^{-i\theta}}{2i}}\) : sert à linéariser.

**Moivre** - \({(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta)}\) : avec le binôme, exprime \(\cos(n\theta)\), \(\sin(n\theta)\) en fonction de \(\cos\theta\), \(\sin\theta\).
