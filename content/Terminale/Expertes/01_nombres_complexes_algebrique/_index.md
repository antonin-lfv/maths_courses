#### Fiche résumé du chapitre

**Forme algébrique** — tout \(z \in \mathbb{C}\) s’écrit de façon unique \(z = x + iy\) (\(x, y\) réels), avec \(i^2 = -1\) ; \(\mathrm{Re}(z) = x\), \(\mathrm{Im}(z) = y\). Deux complexes sont égaux si et seulement si ils ont mêmes parties réelle et imaginaire.

**Quotient** — on multiplie par le conjugué du dénominateur : \((a + ib)(a - ib) = a^2 + b^2\).

**Conjugué** — \(\overline{x + iy} = x - iy\) ; \(\overline{z + z'} = \overline{z} + \overline{z'}\), \(\overline{zz'} = \overline{z}\,\overline{z'}\), \(\overline{z^n} = \overline{z}^n\), \(\overline{\left(\frac{z'}{z}\right)} = \frac{\overline{z'}}{\overline{z}}\) ; \(z + \overline{z} = 2\mathrm{Re}(z)\), \(z - \overline{z} = 2i\,\mathrm{Im}(z)\), \(z\overline{z} = x^2 + y^2\).

**Réels, imaginaires purs** — \(z\) réel \(\iff \overline{z} = z\) ; \(z\) imaginaire pur \(\iff \overline{z} = -z\).

**Binôme de Newton** — \((a + b)^n = \sum\limits_{k=0}^{n} \binom{n}{k} a^k b^{n-k}\) pour tous complexes \(a\), \(b\).

**Équations** — premier degré en \(z\) : isoler \(z\) ; si \(\overline{z}\) apparaît : poser \(z = a + ib\) et identifier.
