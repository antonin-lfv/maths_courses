**Quotient \({\dfrac{d - c}{b - a}}\)** - module \(\dfrac{CD}{AB}\), argument \(\left(\overrightarrow{AB}, \overrightarrow{CD}\right) \ (2\pi)\).

**Avec \({Z = \dfrac{c - a}{b - a}}\)** - \({|Z| = 1 \iff AB = AC}\) ; \(Z\) réel \({\iff}\) \(A, B, C\) alignés ; \(Z\) imaginaire pur \({\iff (AB) \perp (AC)}\) ; \({Z = e^{\pm i\frac{\pi}{3}} \iff ABC}\) équilatéral.

**Racines \(n\)-ièmes de l’unité** - \({z^n = 1}\) a exactement \(n\) solutions \(e^{\frac{2ik\pi}{n}}\), \({0 \leq k \leq n - 1}\) : ensemble \(\mathbb{U}_n\). Images : sommets d’un polygone régulier à \(n\) côtés inscrit dans le cercle trigonométrique (\({n \geq 3}\)).

**Cas usuels** - \({\mathbb{U}_2 = \{\pm 1\}}\), \({\mathbb{U}_3 = \{1, j, j^2\}}\) avec \({j = e^{i\frac{2\pi}{3}}}\), \({j^2 = \overline{j}}\), \({1 + j + j^2 = 0}\) ; \({\mathbb{U}_4 = \{1, i, -1, -i\}}\).

**Somme** - \({1 + \omega + \dots + \omega^{n-1} = 0}\) pour \({\omega = e^{\frac{2i\pi}{n}}}\), \({n \geq 2}\). **Équation \({z^n = a}\)** : solutions \(z_0\,\omega\), \({\omega \in \mathbb{U}_n}\), où \(z_0\) est une solution particulière.
