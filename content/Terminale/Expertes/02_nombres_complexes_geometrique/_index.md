#### Fiche résumé du chapitre

**Affixes** — \(M(x\,;\,y)\) a pour affixe \(z = x + iy\) ; \(\overrightarrow{AB}\) a pour affixe \(z_B - z_A\) ; le milieu de \([AB]\) a pour affixe \(\frac{z_A + z_B}{2}\) ; \(\vec{w} + \vec{w'}\) et \(k\vec{w}\) ont pour affixes \(z + z'\) et \(kz\).

**Module** — \(|x + iy| = \sqrt{x^2 + y^2}\) ; \(OM = |z|\), \(AB = |z_B - z_A|\) ; \(|z|^2 = z\overline{z}\) ; \(|zz'| = |z||z'|\), \(\left|\frac{z'}{z}\right| = \frac{|z'|}{|z|}\), \(|z^n| = |z|^n\) ; \(|z + z'| \leq |z| + |z'|\).

**Ensemble \(\mathbb{U}\)** — complexes de module 1 (cercle trigonométrique) ; stable par produit, inverse et quotient ; \(\frac{1}{z} = \overline{z}\) pour \(z \in \mathbb{U}\).

**Arguments** (\(z \neq 0\)) — \(\cos\theta = \frac{x}{|z|}\), \(\sin\theta = \frac{y}{|z|}\) ; \(\arg(z) = \left(\vec{u}, \overrightarrow{OM}\right)\) et \(\left(\vec{u}, \overrightarrow{AB}\right) = \arg(z_B - z_A) \ (2\pi)\) ; \(\arg(zz') = \arg z + \arg z'\), \(\arg\frac{z}{z'} = \arg z - \arg z'\), \(\arg(z^n) = n\arg z\), \(\arg\overline{z} = -\arg z\), \(\arg(-z) = \arg z + \pi \ (2\pi)\).

**Forme trigonométrique** — \(z = r(\cos\theta + i\sin\theta)\) avec \(r = |z| > 0\), \(\theta = \arg(z)\).
