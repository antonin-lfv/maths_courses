#### Fiche résumé du chapitre

**Expérience aléatoire** - résultat imprévisible ; issues : résultats possibles ; événement : réalisé ou non selon l’issue ; impossible, certain.

**Probabilité** - nombre entre \(0\) (impossible) et \(1\) (certain) ; fraction, décimal ou pourcentage. Si les issues ont toutes la même chance : nombre d’issues favorables divisé par le nombre total d’issues.

**Deux étapes** - tableau à double entrée ou arbre pour recenser toutes les issues ; (A ; B) et (B ; A) sont différentes.
