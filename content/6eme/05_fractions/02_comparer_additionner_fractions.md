## Comparer des fractions

> [!TIP] **Propriétés**
>
> - Si deux fractions ont le **même dénominateur**, la plus grande est celle qui a le plus grand numérateur.
> - Si deux fractions ont le **même numérateur**, la plus grande est celle qui a le plus petit dénominateur.

{{% details title="Exemple" closed="true" %}}
\(\dfrac{7}{9} > \dfrac{4}{9}\) (même dénominateur, \(7 > 4\)). \(\dfrac{5}{6} > \dfrac{5}{8}\) (même numérateur : un sixième est plus grand qu’un huitième).
{{% /details %}}

> [!NOTE] **Méthode — Comparer deux fractions de dénominateurs différents**
>
> Si l’un des dénominateurs est un multiple de l’autre, on écrit les deux fractions avec le même dénominateur, puis on compare les numérateurs.

{{% details title="Exemple" closed="true" %}}
Comparer \(\dfrac{3}{4}\) et \(\dfrac{7}{12}\) : \(\dfrac{3}{4} = \dfrac{9}{12}\), et \(9 > 7\), donc \(\dfrac{3}{4} > \dfrac{7}{12}\).
{{% /details %}}

> [!TIP] **Propriété**
>
> Toute fraction peut être encadrée par deux nombres entiers consécutifs. Si \(a\) et \(b\) sont deux nombres entiers (\(b \neq 0\)), on a \(q \leq \dfrac{a}{b} < q + 1\), où \(q\) est le quotient de la division euclidienne de \(a\) par \(b\).

{{% details title="Exemple" closed="true" %}}
Encadrer \(\dfrac{87}{12}\) : \(87 = (12 \times 7) + 3\), donc \(7 < \dfrac{87}{12} < 8\). En effet \(\frac{87}{12} = 7 + \frac{3}{12} = 7{,}25\).
{{% /details %}}

## Additionner et soustraire

> [!TIP] **Propriété**
>
> Pour additionner (ou soustraire) deux fractions de **même dénominateur**, on additionne (ou on soustrait) les numérateurs et on garde le dénominateur commun :
> \[
\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c} \qquad \text{et} \qquad \frac{a}{c} - \frac{b}{c} = \frac{a - b}{c}.
\]

{{% details title="Exemple" closed="true" %}}
\(\dfrac{2}{7} + \dfrac{3}{7} = \dfrac{5}{7}\) ; \(\dfrac{11}{5} - \dfrac{4}{5} = \dfrac{7}{5}\).
{{% /details %}}

> [!NOTE] **Méthode — Additionner deux fractions de dénominateurs différents**
>
> On écrit d’abord les deux fractions avec le même dénominateur (lorsque l’un des dénominateurs est un multiple de l’autre, on prend le plus grand), puis on additionne.

{{% details title="Exemple" closed="true" %}}
\[
\frac{1}{3} + \frac{5}{6} = \frac{1 \times 2}{3 \times 2} + \frac{5}{6} = \frac{2}{6} + \frac{5}{6} = \frac{7}{6}, \qquad \frac{9}{10} - \frac{1}{5} = \frac{9}{10} - \frac{2}{10} = \frac{7}{10}.
\]
{{% /details %}}

> [!IMPORTANT] **Remarque**
>
> On n’additionne **jamais** les dénominateurs : \(\frac{1}{3} + \frac{1}{3} = \frac{2}{3}\), et non \(\frac{2}{6}\).

## S’entraîner

> [!NOTE] **Exercice résolu**
>
> 1. Ranger dans l’ordre croissant : \(\dfrac{5}{8}\) ; \(\dfrac{3}{4}\) ; \(\dfrac{1}{2}\) ; \(\dfrac{7}{8}\).
> 2. Calculer \(\dfrac{3}{4} + \dfrac{1}{8}\) et \(2 - \dfrac{3}{5}\).

{{% details title="Solution commentée" closed="true" %}}
1. On écrit tout en huitièmes : \(\frac{5}{8}\), \(\frac{6}{8}\), \(\frac{4}{8}\), \(\frac{7}{8}\). Ordre croissant : \(\frac{1}{2} < \frac{5}{8} < \frac{3}{4} < \frac{7}{8}\).
2. \(\dfrac{3}{4} + \dfrac{1}{8} = \dfrac{6}{8} + \dfrac{1}{8} = \dfrac{7}{8}\). \(2 = \dfrac{10}{5}\), donc \(2 - \dfrac{3}{5} = \dfrac{10}{5} - \dfrac{3}{5} = \dfrac{7}{5}\).
{{% /details %}}
