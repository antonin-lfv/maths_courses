### Exercice 1

1. Donner l’écriture décimale de \(\dfrac{9}{4}\), \(\dfrac{3}{5}\) et \(\dfrac{27}{100}\).
2. Quel nombre faut-il multiplier par \(7\) pour obtenir \(3\) ?

{{% details title="Solution" closed="true" %}}
1. \(2{,}25\) ; \(0{,}6\) ; \(0{,}27\).
2. \(\dfrac{3}{7}\), car \(\dfrac{3}{7} \times 7 = 3\).
{{% /details %}}

### Exercice 2

Simplifier : \(\dfrac{14}{21}\) ; \(\dfrac{36}{48}\) ; \(\dfrac{50}{125}\).

{{% details title="Solution" closed="true" %}}
\(\dfrac{14}{21} = \dfrac{2}{3}\) (division par \(7\)) ; \(\dfrac{36}{48} = \dfrac{3}{4}\) (par \(12\)) ; \(\dfrac{50}{125} = \dfrac{2}{5}\) (par \(25\)).
{{% /details %}}

### Exercice 3

1. Encadrer \(\dfrac{58}{9}\) entre deux entiers consécutifs.
2. Comparer \(\dfrac{5}{6}\) et \(\dfrac{11}{12}\).

{{% details title="Solution" closed="true" %}}
1. \(58 = 9 \times 6 + 4\), donc \(6 < \dfrac{58}{9} < 7\).
2. \(\dfrac{5}{6} = \dfrac{10}{12} < \dfrac{11}{12}\).
{{% /details %}}

### Exercice 4

Calculer : \(\dfrac{4}{9} + \dfrac{2}{9}\) ; \(\dfrac{7}{10} - \dfrac{1}{2}\) ; \(\dfrac{2}{5} + \dfrac{3}{20}\) ; \(\dfrac{5}{7} \times 3\).

{{% details title="Solution" closed="true" %}}
\(\dfrac{6}{9}\) (ou \(\dfrac{2}{3}\)) ; \(\dfrac{7}{10} - \dfrac{5}{10} = \dfrac{2}{10}\) ; \(\dfrac{8}{20} + \dfrac{3}{20} = \dfrac{11}{20}\) ; \(\dfrac{15}{7}\).
{{% /details %}}

### Exercice 5

Un collège compte \(560\) élèves ; les \(\dfrac{3}{7}\) sont demi-pensionnaires, et \(25\,\%\) des élèves pratiquent un sport à l’association sportive.
1. Combien d’élèves sont demi-pensionnaires ?
2. Combien d’élèves pratiquent un sport à l’association sportive ?

{{% details title="Solution" closed="true" %}}
1. \(\dfrac{3}{7} \times 560 = 3 \times 80 = 240\) élèves.
2. \(\dfrac{25}{100} \times 560 = 140\) élèves.
{{% /details %}}
