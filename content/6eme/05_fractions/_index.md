{{% fiche %}}
**Fraction quotient** - \({\dfrac{a}{b} = a \div b}\) (\({b \neq 0}\)) ; \({\dfrac{a}{b} \times b = a}\) ; un quotient n’est pas toujours décimal (\(\dfrac{1}{3}\)).

**Fractions égales** - on peut multiplier ou diviser numérateur et dénominateur par un même nombre non nul ; simplifier.

**Comparer** - même dénominateur : le plus grand numérateur l’emporte ; même numérateur : le plus petit dénominateur l’emporte ; sinon, réduire au même dénominateur. Encadrer entre deux entiers avec la division euclidienne.

**Additionner, soustraire** - même dénominateur : on opère sur les numérateurs ; jamais d’addition des dénominateurs.

**Proportions** - \({\dfrac{a}{b} \times k = \dfrac{a \times k}{b}}\) ; fraction d’une quantité : on multiplie ; \(t\,\%\) d’une quantité : \({\dfrac{t}{100} \times}\) quantité.
