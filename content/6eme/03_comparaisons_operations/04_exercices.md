### Exercice 1

Compléter avec \({<}\), \({>}\) ou \({=}\) : a) \(3{,}7 \dots 3{,}69\) ; b) \(0{,}08 \dots 0{,}8\) ; c) \(12{,}50 \dots 12{,}5\) ; d) \(7{,}099 \dots 7{,}1\).

{{% details title="Solution" closed="true" %}}
a) \({3{,}7 > 3{,}69}\) ; b) \({0{,}08 < 0{,}8}\) ; c) \({12{,}50 = 12{,}5}\) ; d) \({7{,}099 < 7{,}1}\).
{{% /details %}}

### Exercice 2

1. Encadrer \(15{,}482\) à l’unité, puis au centième.
2. Donner l’arrondi de \(15{,}482\) au dixième.
3. Intercaler un nombre entre \(2{,}6\) et \(2{,}61\).

{{% details title="Solution" closed="true" %}}
1. \({15 < 15{,}482 < 16}\) ; \({15{,}48 < 15{,}482 < 15{,}49}\).
2. \({15{,}4 < 15{,}482 < 15{,}5}\), plus proche de \(15{,}5\) : arrondi \(15{,}5\).
3. Par exemple \(2{,}605\).
{{% /details %}}

### Exercice 3

Poser et effectuer : a) \({208{,}4 + 39{,}76}\) ; b) \({100 - 47{,}35}\) ; c) \({3{,}14 \times 2{,}6}\).

{{% details title="Solution" closed="true" %}}
a) \(248{,}16\) ; b) \(52{,}65\) ; c) \({314 \times 26 = 8\,164}\), d’où \(8{,}164\).
{{% /details %}}

### Exercice 4

Calculer mentalement : \({0{,}25 \times 7{,}9 \times 4}\) ; \({56{,}3 \times 100}\) ; \({56{,}3 \times 0{,}01}\) ; \({1{,}8 + 4{,}6 + 0{,}2 + 3{,}4}\).

{{% details title="Solution" closed="true" %}}
\({1 \times 7{,}9 = 7{,}9}\) ; \(5\,630\) ; \(0{,}563\) ; \({(1{,}8 + 0{,}2) + (4{,}6 + 3{,}4) = 2 + 8 = 10}\).
{{% /details %}}

### Exercice 5

Un rouleau de tissu mesure \(25\) m. Une couturière en coupe \(3\) morceaux de \(4{,}75\) m. Quelle longueur de tissu reste-t-il ? Vérifier avec un ordre de grandeur.

{{% details title="Solution" closed="true" %}}
\({3 \times 4{,}75 = 14{,}25}\) m, donc il reste \({25 - 14{,}25 = 10{,}75}\) m. Ordre de grandeur : \({3 \times 5 = 15}\) et \({25 - 15 = 10}\) : cohérent.
{{% /details %}}
