### Exercice 1

Parmi les fonctions suivantes, lesquelles sont affines ? linéaires ? Préciser \(m\) et \(p\).
\({f(x) = 5 - 2x}\) ; \({g(x) = \dfrac{3x}{4}}\) ; \({h(x) = x(x - 1)}\) ; \({k(x) = 2(x + 3) - 6}\).

{{% details title="Solution" closed="true" %}}
- \(f\) : affine, \({m = -2}\), \({p = 5}\).
- \(g\) : linéaire (donc affine), \({m = 0{,}75}\), \({p = 0}\).
- \({h(x) = x^2 - x}\) : ni affine ni linéaire.
- \({k(x) = 2x + 6 - 6 = 2x}\) : linéaire, \({m = 2}\).
{{% /details %}}

### Exercice 2

Soit \({f(x) = 4x - 3}\). Calculer \({f(-2)}\), puis l’antécédent de \(9\).

{{% details title="Solution" closed="true" %}}
\({f(-2) = -8 - 3 = -11}\). \({4x - 3 = 9}\) donne \({x = 3}\).
{{% /details %}}

### Exercice 3

La fonction affine \(g\) vérifie \({g(-1) = 7}\) et \({g(3) = -1}\). Déterminer \(g(x)\).

{{% details title="Solution" closed="true" %}}
\({m = \dfrac{-1 - 7}{3 - (-1)} = \dfrac{-8}{4} = -2}\) ; \({g(-1) = 2 + p = 7}\), donc \({p = 5}\). \({g(x) = -2x + 5}\).
{{% /details %}}

### Exercice 4

Une fonction linéaire \(\ell\) vérifie \({\ell(5) = -3}\). Déterminer son coefficient et calculer \(\ell(20)\).

{{% details title="Solution" closed="true" %}}
\({5m = -3}\), donc \({m = -0{,}6}\). \({\ell(20) = -12}\).
{{% /details %}}

### Exercice 5

Une salle de sport propose deux tarifs. Tarif A : \(12\) € la séance. Tarif B : abonnement de \(90\) € puis \(6\) € la séance. On note \(x\) le nombre de séances, \(A(x)\) et \(B(x)\) les prix.
1. Exprimer \(A(x)\) et \(B(x)\). Laquelle de ces fonctions est linéaire ?
2. Pour combien de séances les deux tarifs sont-ils égaux ?

{{% details title="Solution" closed="true" %}}
1. \({A(x) = 12x}\) (linéaire, le prix est proportionnel au nombre de séances) et \({B(x) = 6x + 90}\) (affine).
2. \({12x = 6x + 90}\), soit \({6x = 90}\), \({x = 15}\) séances (\(180\) € dans les deux cas).
{{% /details %}}

### Exercice 6

Une ville voit sa population augmenter de \(4\,\%\). Exprimer la nouvelle population \(f(x)\) en fonction de l’ancienne \(x\). Quelle était la population si elle atteint \(13\,000\) habitants après l’augmentation ?

{{% details title="Solution" closed="true" %}}
\({f(x) = 1{,}04x}\). \({1{,}04x = 13\,000}\) donne \({x = 12\,500}\) habitants.
{{% /details %}}
