### Exercice 1

Réduire : \(A = 4x - (7 - 3x) + 2\) ; \(B = x^2 - (2x^2 - 5x) - 3x\).

{{% details title="Solution" closed="true" %}}
\(A = 4x - 7 + 3x + 2 = 7x - 5\) ; \(B = x^2 - 2x^2 + 5x - 3x = -x^2 + 2x\).
{{% /details %}}

### Exercice 2

L’égalité \((x + 2)^2 = x^2 + 4\) est-elle vraie pour tout nombre \(x\) ?

{{% details title="Solution" closed="true" %}}
Non : pour \(x = 1\), \((1 + 2)^2 = 9\) alors que \(1^2 + 4 = 5\). Ce contre-exemple suffit.
{{% /details %}}

### Exercice 3

Développer et réduire : \(C = -3(2x - 5)\) ; \(D = (x - 6)(2x + 1)\) ; \(E = (4x + 3)(4x - 3)\).

{{% details title="Solution" closed="true" %}}
\(C = -6x + 15\) ; \(D = 2x^2 + x - 12x - 6 = 2x^2 - 11x - 6\) ; \(E = 16x^2 - 9\).
{{% /details %}}

### Exercice 4

Factoriser : \(F = 12x - 18\) ; \(G = 7x^2 + 14x\) ; \(H = x^2 - 100\) ; \(I = 25 - 4x^2\).

{{% details title="Solution" closed="true" %}}
\(F = 6(2x - 3)\) ; \(G = 7x(x + 2)\) ; \(H = (x + 10)(x - 10)\) ; \(I = (5 + 2x)(5 - 2x)\).
{{% /details %}}

### Exercice 5

Factoriser \(J = (x + 1)(3x - 2) - (x + 1)(x - 5)\).

{{% details title="Solution" closed="true" %}}
\(J = (x + 1)\big[(3x - 2) - (x - 5)\big] = (x + 1)(3x - 2 - x + 5) = (x + 1)(2x + 3)\).
{{% /details %}}

### Exercice 6

Sans calculatrice, calculer \(51^2 - 49^2\) et \(998 \times 1\,002\).

{{% details title="Solution" closed="true" %}}
\(51^2 - 49^2 = (51 + 49)(51 - 49) = 100 \times 2 = 200\). \(998 \times 1\,002 = (1\,000 - 2)(1\,000 + 2) = 1\,000\,000 - 4 = 999\,996\).
{{% /details %}}

### Exercice 7

Démontrer que, pour tout entier \(n\), le nombre \((n + 1)^2 - (n - 1)^2\) est un multiple de \(4\).

{{% details title="Solution" closed="true" %}}
Avec la différence de deux carrés : \((n + 1)^2 - (n - 1)^2 = \big[(n + 1) + (n - 1)\big]\big[(n + 1) - (n - 1)\big] = 2n \times 2 = 4n\), qui est un multiple de \(4\).
{{% /details %}}
