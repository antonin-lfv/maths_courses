#### Fiche résumé du chapitre

**Simplifier** — \(a - (b + c) = a - b - c\) ; une égalité se prouve par le calcul, se réfute par un contre-exemple ; la nature d’une expression est donnée par la dernière opération.

**Développer** — \(k(a + b) = ka + kb\) ; \((a + b)(c + d) = ac + ad + bc + bd\) ; \((a + b)(a - b) = a^2 - b^2\).

**Factoriser** — \(ka + kb = k(a + b)\) (facteur commun) ; \(a^2 - b^2 = (a + b)(a - b)\).
