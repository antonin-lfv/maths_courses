## Factoriser avec un facteur commun

> [!TIP] **Définition**
>
> **Factoriser**, c’est transformer une somme ou une différence en un produit.

> [!TIP] **Propriété**
>
> Soit \(k\), \(a\) et \(b\) des nombres.
> \[
ka + kb = k(a + b) \qquad \text{et} \qquad ka - kb = k(a - b).
\]
> Le nombre \(k\), présent dans chaque terme, est le **facteur commun**.

{{% details title="Exemple 1" closed="true" %}}
\(A = 8x + 20 = 4 \times 2x + 4 \times 5 = 4(2x + 5)\) : le facteur commun est \(4\).
{{% /details %}}

{{% details title="Exemple 2" closed="true" %}}
\(B = 5x^2 - 3x = x \times 5x - x \times 3 = x(5x - 3)\) : le facteur commun est \(x\).
{{% /details %}}

{{% details title="Exemple 3" closed="true" %}}
\(C = 6a^2 + a\). On fait apparaître le facteur commun \(a\) dans le second terme en écrivant \(a = a \times 1\) :
\[
C = a \times 6a + a \times 1 = a(6a + 1).
\]
{{% /details %}}

{{% details title="Exemple 4 — facteur commun entre parenthèses" closed="true" %}}
\(D = (x + 4)(2x - 1) + (x + 4)(x + 3)\). Le facteur commun est \((x + 4)\) :
\[
D = (x + 4)\big[(2x - 1) + (x + 3)\big] = (x + 4)(3x + 2).
\]
{{% /details %}}

## Factoriser une différence de deux carrés

> [!TIP] **Propriété**
>
> Soit \(a\) et \(b\) des nombres.
> \[
a^2 - b^2 = (a + b)(a - b).
\]

> [!IMPORTANT] **Remarque**
>
> C’est l’identité remarquable de la page précédente, lue « de droite à gauche ». Elle permet de factoriser une expression écrite comme une différence de deux carrés, même sans facteur commun apparent.

{{% details title="Exemples" closed="true" %}}
- \(x^2 - 49 = x^2 - 7^2 = (x + 7)(x - 7)\).
- \(16 - 9y^2 = 4^2 - (3y)^2 = (4 + 3y)(4 - 3y)\).
- \(x^2 - 5 = x^2 - (\sqrt{5})^2 = (x + \sqrt{5})(x - \sqrt{5})\).
{{% /details %}}

> [!NOTE] **Exercice résolu**
>
> Factoriser \(E = (2x + 1)^2 - 9\) et \(F = 3x(x - 2) - (x - 2)\).

{{% details title="Solution commentée" closed="true" %}}
- \(E\) est une différence de deux carrés, avec \(a = 2x + 1\) et \(b = 3\) :
\[
E = (2x + 1 + 3)(2x + 1 - 3) = (2x + 4)(2x - 2).
\]
- Dans \(F\), le facteur commun est \((x - 2)\) ; on écrit \((x - 2) = (x - 2) \times 1\) :
\[
F = (x - 2)(3x - 1).
\]
{{% /details %}}
