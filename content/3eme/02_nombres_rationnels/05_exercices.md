### Exercice 1

Calculer : \({A = -7 + 2{,}5 - (-4{,}5)}\) ; \({B = (-3) \times (-2) \times (-5)}\) ; \({C = \dfrac{-36}{-4} + 6 \times (-2)}\).

{{% details title="Solution" closed="true" %}}
\({A = -7 + 2{,}5 + 4{,}5 = 0}\) ; \({B = 6 \times (-5) = -30}\) ; \({C = 9 + (-12) = -3}\).
{{% /details %}}

### Exercice 2

Calculer : \({D = (-3)^4}\) ; \({E = -3^4}\) ; \({F = 2^{-3}}\) ; \({G = 1 - 2 \times 5^2}\).

{{% details title="Solution" closed="true" %}}
\({D = 81}\) ; \({E = -81}\) ; \({F = \dfrac{1}{8}}\) ; \({G = 1 - 2 \times 25 = 1 - 50 = -49}\).
{{% /details %}}

### Exercice 3

Donner l’écriture scientifique de : \(780\,000\) ; \(0{,}000\,094\) ; \({52 \times 10^{-6}}\) ; \({\dfrac{3 \times 10^4 \times 5 \times 10^{-7}}{6 \times 10^{2}}}\).

{{% details title="Solution" closed="true" %}}
\({7{,}8 \times 10^5}\) ; \({9{,}4 \times 10^{-5}}\) ; \({5{,}2 \times 10^{-5}}\) ; \({\dfrac{15}{6} \times 10^{4 - 7 - 2} = 2{,}5 \times 10^{-5}}\).
{{% /details %}}

### Exercice 4

Rendre irréductibles les fractions \(\dfrac{84}{120}\) et \({\dfrac{75}{-135}}\).

{{% details title="Solution" closed="true" %}}
\({84 = 2^2 \times 3 \times 7}\), \({120 = 2^3 \times 3 \times 5}\) : \({\dfrac{84}{120} = \dfrac{7}{10}}\). \({75 = 3 \times 5^2}\), \({135 = 3^3 \times 5}\) : \({\dfrac{75}{-135} = -\dfrac{5}{9}}\).
{{% /details %}}

### Exercice 5

Calculer et simplifier : \({H = \dfrac{7}{6} - \dfrac{2}{9}}\) ; \({I = \dfrac{-4}{15} \times \dfrac{25}{8}}\) ; \({J = \dfrac{3}{5} \div \dfrac{9}{10}}\).

{{% details title="Solution" closed="true" %}}
\({H = \dfrac{21}{18} - \dfrac{4}{18} = \dfrac{17}{18}}\) ; \({I = -\dfrac{100}{120} = -\dfrac{5}{6}}\) ; \({J = \dfrac{3}{5} \times \dfrac{10}{9} = \dfrac{30}{45} = \dfrac{2}{3}}\).
{{% /details %}}

### Exercice 6

La masse d’un atome de carbone est environ \({2 \times 10^{-23}}\) g. Combien d’atomes de carbone y a-t-il, environ, dans \(12\) g de carbone ? Donner le résultat en écriture scientifique.

{{% details title="Solution" closed="true" %}}
\({\dfrac{12}{2 \times 10^{-23}} = 6 \times 10^{23}}\) atomes environ.
{{% /details %}}
