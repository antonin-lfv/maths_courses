## Addition et soustraction

> [!TIP] **Définition**
>
> - Si deux nombres relatifs ont le **même signe**, leur somme a ce signe commun et, pour distance à zéro, la **somme** de leurs distances à zéro.
> - Si deux nombres relatifs sont de **signes contraires**, leur somme a le signe de celui qui a la plus grande distance à zéro et, pour distance à zéro, la **différence** de leurs distances à zéro.

> [!TIP] **Propriété**
>
> Soustraire un nombre relatif revient à ajouter son **opposé** : \(a - b = a + (-b)\).

{{% details title="Exemples" closed="true" %}}
- \(-4{,}5 + (-2{,}7)\) : même signe (négatif), distances \(4{,}5 + 2{,}7 = 7{,}2\), donc \(-4{,}5 + (-2{,}7) = -7{,}2\).
- \(-8 + 3{,}5\) : signes contraires ; \(8 > 3{,}5\), donc le résultat est négatif, de distance à zéro \(8 - 3{,}5 = 4{,}5\) : \(-8 + 3{,}5 = -4{,}5\).
- \(2{,}4 - (-6) = 2{,}4 + 6 = 8{,}4\).
{{% /details %}}

## Multiplication et division

> [!TIP] **Définition et propriété**
>
> Pour calculer le produit (ou le quotient) de deux nombres relatifs, on détermine son signe, puis on multiplie (ou on divise) leurs distances à zéro.
> - Le produit (ou le quotient) de deux nombres relatifs de **même signe** est **positif**.
> - Le produit (ou le quotient) de deux nombres relatifs de **signes contraires** est **négatif**.

{{% details title="Exemples" closed="true" %}}
\[
(-6) \times (-2{,}5) = 15, \qquad 4 \times (-1{,}2) = -4{,}8, \qquad \frac{-21}{-3} = 7, \qquad \frac{18}{-4} = -4{,}5.
\]
{{% /details %}}

> [!IMPORTANT] **Remarque**
>
> Dans un produit de plusieurs facteurs non nuls, le résultat est positif si le nombre de facteurs négatifs est pair, négatif s’il est impair. Par exemple, \((-1) \times (-2) \times (-3) = -6\) (trois facteurs négatifs).

> [!TIP] **Propriétés**
>
> Soit \(a\) et \(b\) deux nombres relatifs, avec \(b \neq 0\).
> - \((-1) \times a = -a\) : multiplier par \(-1\) donne l’opposé.
> - \(\dfrac{-a}{b} = \dfrac{a}{-b} = -\dfrac{a}{b}\) et \(\dfrac{-a}{-b} = \dfrac{a}{b}\).

{{% details title="Exemples" closed="true" %}}
- \((-1) \times (-9{,}3) = 9{,}3\), l’opposé de \(-9{,}3\).
- \(\dfrac{-5}{8} = \dfrac{5}{-8} = -\dfrac{5}{8}\), et \(\dfrac{-7}{-11} = \dfrac{7}{11}\).
{{% /details %}}

> [!NOTE] **Exercice résolu**
>
> Calculer \(A = -3 + 5 \times (-4) - (-12)\) et \(B = \dfrac{(-2) \times 9}{-6 + 3}\).

{{% details title="Solution commentée" closed="true" %}}
- La multiplication est prioritaire : \(5 \times (-4) = -20\). Donc \(A = -3 + (-20) + 12 = -23 + 12 = -11\).
- Numérateur : \((-2) \times 9 = -18\) ; dénominateur : \(-6 + 3 = -3\). Donc \(B = \dfrac{-18}{-3} = 6\) (quotient de deux négatifs, positif).
{{% /details %}}
