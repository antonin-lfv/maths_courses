### Exercice 1

Le nombre \(-2\) est-il solution de l’équation \(x^2 + 3x = -2\) ?

{{% details title="Solution" closed="true" %}}
Pour \(x = -2\) : \((-2)^2 + 3 \times (-2) = 4 - 6 = -2\). L’égalité est vraie : \(-2\) est solution.
{{% /details %}}

### Exercice 2

Résoudre : \(5x + 8 = -7\) ; \(4 - 3x = 2x + 19\) ; \(3(2x - 1) = 4(x + 2)\).

{{% details title="Solution" closed="true" %}}
- \(5x = -15\), \(x = -3\).
- \(-5x = 15\), \(x = -3\).
- \(6x - 3 = 4x + 8\), \(2x = 11\), \(x = 5{,}5\).
{{% /details %}}

### Exercice 3

Résoudre : \((x - 7)(3x + 6) = 0\) ; \(4x^2 - 9 = 0\) ; \(x^2 + 2x = 0\).

{{% details title="Solution" closed="true" %}}
- \(x = 7\) ou \(x = -2\).
- \((2x + 3)(2x - 3) = 0\) : \(x = -\dfrac{3}{2}\) ou \(x = \dfrac{3}{2}\).
- \(x(x + 2) = 0\) : \(x = 0\) ou \(x = -2\).
{{% /details %}}

### Exercice 4

Résoudre : \(x^2 = 81\) ; \(x^2 = 7\) ; \(3x^2 + 12 = 0\).

{{% details title="Solution" closed="true" %}}
\(x = 9\) ou \(x = -9\) ; \(x = \sqrt{7}\) ou \(x = -\sqrt{7}\) ; \(x^2 = -4\) : aucune solution.
{{% /details %}}

### Exercice 5

La somme de trois nombres entiers consécutifs est \(156\). Quels sont ces nombres ?

{{% details title="Solution" closed="true" %}}
Soit \(n\) le plus petit : \(n + (n + 1) + (n + 2) = 156\), soit \(3n + 3 = 156\), \(3n = 153\), \(n = 51\). Les nombres sont \(51\), \(52\) et \(53\).
{{% /details %}}

### Exercice 6

Un père a \(41\) ans et sa fille \(9\) ans. Dans combien d’années l’âge du père sera-t-il le triple de celui de sa fille ?

{{% details title="Solution" closed="true" %}}
Dans \(x\) années : \(41 + x = 3(9 + x)\), soit \(41 + x = 27 + 3x\), \(14 = 2x\), \(x = 7\). Dans \(7\) ans (le père aura \(48\) ans, la fille \(16\) ans, et \(48 = 3 \times 16\)).
{{% /details %}}
