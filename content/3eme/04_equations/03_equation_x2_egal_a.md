## Équations du type \(x^2 = a\)

> [!TIP] **Propriété**
>
> Soit \(a\) un nombre.
> - Si \(a > 0\), l’équation \(x^2 = a\) a deux solutions : \(\sqrt{a}\) et \(-\sqrt{a}\).
> - Si \(a = 0\), l’équation \(x^2 = 0\) a une seule solution : \(0\).
> - Si \(a < 0\), l’équation \(x^2 = a\) n’a aucune solution (un carré n’est jamais négatif).

> [!IMPORTANT] **Remarque**
>
> Pour \(a > 0\), on peut le démontrer avec une équation produit : \(x^2 = a\) équivaut à \(x^2 - (\sqrt{a})^2 = 0\), soit \((x - \sqrt{a})(x + \sqrt{a}) = 0\), donc \(x = \sqrt{a}\) ou \(x = -\sqrt{a}\).

{{% details title="Exemples" closed="true" %}}
- \(x^2 = 36\) a deux solutions : \(6\) et \(-6\).
- \(x^2 = 11\) a deux solutions : \(\sqrt{11}\) et \(-\sqrt{11}\) (environ \(3{,}32\) et \(-3{,}32\)).
- \(x^2 = 0\) a pour unique solution \(0\).
- \(x^2 = -9\) n’a aucune solution.
{{% /details %}}

> [!NOTE] **Méthode**
>
> On isole d’abord \(x^2\) dans un membre (avec les règles de transformation des égalités), puis on applique la propriété selon le signe de l’autre membre.

> [!NOTE] **Exercice résolu**
>
> 1. Résoudre \(2x^2 - 7 = 43\).
> 2. Résoudre \(x^2 + 5 = 1\).
> 3. Un carré a une aire de \(20\) cm². Quelle est la longueur de son côté ?

{{% details title="Solution commentée" closed="true" %}}
1. \(2x^2 = 50\), donc \(x^2 = 25\). Comme \(25 > 0\), les solutions sont \(5\) et \(-5\).
2. \(x^2 = 1 - 5 = -4\). Un carré ne peut pas être négatif : l’équation n’a aucune solution.
3. Le côté \(c\) vérifie \(c^2 = 20\), donc \(c = \sqrt{20}\) ou \(c = -\sqrt{20}\). Une longueur est positive : \(c = \sqrt{20} \approx 4{,}47\) cm.
{{% /details %}}
