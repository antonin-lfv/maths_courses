### Exercice 1

Soit \({f(x) = x^2 - 3x + 1}\). Calculer \(f(0)\), \(f(2)\) et \({f(-3)}\).

{{% details title="Solution" closed="true" %}}
\({f(0) = 1}\) ; \({f(2) = 4 - 6 + 1 = -1}\) ; \({f(-3) = 9 + 9 + 1 = 19}\).
{{% /details %}}

### Exercice 2

Soit \({g(x) = -4x + 6}\). Déterminer l’antécédent de \({-10}\) par \(g\).

{{% details title="Solution" closed="true" %}}
\({-4x + 6 = -10}\), soit \({-4x = -16}\), donc \({x = 4}\).
{{% /details %}}

### Exercice 3

Traduire par une égalité : « l’image de \(5\) par la fonction \(k\) est \({-2}\) », puis « \(7\) est un antécédent de \(0\) par \(k\) ».

{{% details title="Solution" closed="true" %}}
\({k(5) = -2}\) ; \({k(7) = 0}\).
{{% /details %}}

### Exercice 4

Soit \({p(x) = x^2}\). Déterminer les antécédents de \(49\), de \(0\) et de \({-1}\) par \(p\).

{{% details title="Solution" closed="true" %}}
\({x^2 = 49}\) : \(7\) et \({-7}\). \({x^2 = 0}\) : \(0\). \({x^2 = -1}\) : aucun antécédent.
{{% /details %}}

### Exercice 5

Un programme de calcul consiste à : choisir un nombre, lui ajouter \(3\), multiplier le résultat par le nombre de départ. On note \(f(x)\) le résultat obtenu à partir de \(x\).
1. Exprimer \(f(x)\) en fonction de \(x\).
2. Calculer l’image de \({-5}\).
3. Déterminer les antécédents de \(0\).

{{% details title="Solution" closed="true" %}}
1. \({f(x) = (x + 3) \times x = x^2 + 3x}\).
2. \(f(-5) = (-5 + 3) \times (-5) = (-2) \times (-5) = 10\).
3. \({x(x + 3) = 0}\) : \({x = 0}\) ou \({x = -3}\).
{{% /details %}}

### Exercice 6

Le point \({P(-1\,;\,4)}\) appartient-il à la courbe de la fonction \({q : x \mapsto 2x^2 - x + 1}\) ?

{{% details title="Solution" closed="true" %}}
\({q(-1) = 2 + 1 + 1 = 4}\) : oui, \(P\) appartient à la courbe.
{{% /details %}}
