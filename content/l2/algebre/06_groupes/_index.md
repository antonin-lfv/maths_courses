Groupes, sous-groupes, morphismes, ordre d’un élément, théorème de Lagrange et groupe symétrique.

{{< sommaire >}}

{{% fiche %}}
**Groupe** - loi associative, élément neutre, tout élément a un symétrique. Abélien si la loi est commutative.

**Sous-groupe** - \(H\) non vide et \({xy^{-1} \in H}\) pour tous \({x, y \in H}\). Sous-groupes de \((\mathbb{Z}, +)\) : les \(n\mathbb{Z}\).

**Morphisme** - \({f(xy) = f(x)f(y)}\) ; \({f(e) = e'}\), \({f(x^{-1}) = f(x)^{-1}}\) ; \(\ker f\) et \(\operatorname{Im} f\) sont des sous-groupes ; \(f\) injectif \(\iff\) \({\ker f = \{e\}}\).

**Ordre de \(x\)** - plus petit \({n \geq 1}\) tel que \({x^n = e}\) ; alors \({x^k = e \iff n \mid k}\).

**Lagrange** - dans un groupe fini, l’ordre d’un sous-groupe et l’ordre d’un élément divisent l’ordre du groupe ; \({x^{|G|} = e}\).

**Groupe cyclique** - engendré par un élément ; d’ordre \(n\) : isomorphe à \(\mathbb{Z}/n\mathbb{Z}\). Un groupe d’ordre premier est cyclique.

**Groupe symétrique** - \({|\mathfrak{S}_n| = n!}\) ; toute permutation est produit de cycles à supports disjoints ; signature \({\varepsilon(\sigma\tau) = \varepsilon(\sigma)\varepsilon(\tau)}\), \({-1}\) pour une transposition, \({(-1)^{p-1}}\) pour un \(p\)-cycle.
