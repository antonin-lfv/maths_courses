Univers, événements, tribus, probabilités et leurs propriétés.

{{< sommaire >}}

{{% fiche %}}
**Tribu** - contient \(\Omega\), stable par complémentaire et par réunion dénombrable.

**Probabilité** - \({P(\Omega) = 1}\) et \(\sigma\)-additivité : \({P\left(\bigcup A_n\right) = \sum P(A_n)}\) pour des événements deux à deux incompatibles.

**Règles** - \({P(\overline{A}) = 1 - P(A)}\) ; \({A \subset B \Rightarrow P(A) \leq P(B)}\) ; \({P(A \cup B) = P(A) + P(B) - P(A \cap B)}\) ; \({P\left(\bigcup A_n\right) \leq \sum P(A_n)}\).

**Équiprobabilité** - \({P(A) = \dfrac{|A|}{|\Omega|}}\) (univers fini).

**Univers dénombrable** - \(P\) est déterminée par les \({p_\omega = P(\{\omega\}) \geq 0}\) de somme \(1\).

**Continuité monotone** - \((A_n)\) croissante : \({P\left(\bigcup A_n\right) = \lim P(A_n)}\) ; décroissante : \({P\left(\bigcap A_n\right) = \lim P(A_n)}\).

**Presque sûr / négligeable** - probabilité \(1\) / probabilité \(0\) (ce qui ne veut pas dire certain / impossible).
